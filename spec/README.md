# 번역 규칙

이 폴더의 파일은 엔진이 내야 하는 출력을 정한 규칙입니다. 고친 번역과 검토는 이 규칙에 맞춰 판단합니다.
규칙마다 영역 접두어와 번호로 된 id(`NUM-1`)가 있고, 지운 규칙의 id는 다시 쓰지 않습니다. "~한다", "~하지 않는다"는
반드시 지킬 것이고, "되도록 ~한다"는 다른 규칙과 부딪치지 않을 때 지킬 것입니다. 규칙을 지키게 하는 사례 파일은
`tests/rules/`에 있고, 그 파일 첫 줄에 `# 규칙: NUM-1, NUM-3`처럼 id를 적습니다. 엔진이 아직 따르지 않는 규칙에는
`현재:` 줄이 있습니다. 규칙과 어긋나는 변경은 같은 변경에서 그 규칙과 사례를 함께 고칩니다.

| 파일 | 영역 |
|---|---|
| [numbers.md](numbers.md) | 숫자와 띄어쓰기 (`NUM`) |
| [layout.md](layout.md) | 배치 (`LAY`) |
| [words.md](words.md) | 낱말 (`LEX`) |
| [speech.md](speech.md) | 말투 (`SPC`) |
| [sounds.md](sounds.md) | 소리 (`SND`) |
