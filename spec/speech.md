# 말투

## SPC-1 따옴표 안 말투는 원문의 표지를 따른다

「」 안의 기본 말투는 -다로 끝나는 strict이고, soft는 옵션으로만 켠다. 원문 대사에 반말 표지(よ, ね, わ, じゃん,
ちゃう, てる, 반말 의문)가 있으면 반말로, 예스러운 말투나 거만한 말투의 표지(ておる, じゃ, ぬ, せよ, である)가
있으면 -다로, です와 ます는 높임말로 옮긴다. 되풀이한 형용사의 외침과 투덜거림(痛い痛い 아파 아파, 寒い寒い 춥다 추워)은
표지가 없어도 SND-2를 따른다. です, ます, ください로 높여 말한 따옴표 안의 でしょ는 그 따옴표에
반말 표지가 없으면 높임말로 동의를 구한다(몰랐죠?, 높죠?). なさい만 있는 따옴표는 높임말이 아니다. っす는
아랫사람의 가벼운 높임이므로 해요체로 옮긴다. 표지가 없으면 기본 말투를 바꾸지 않는다. 말하는 사람을 추적해
말투를 정하지 않는다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 「違う。そうじゃないよ」 | 「아니야. 그렇지 않아」 | 고침 |
| 「ずっと待ってる。寒いね」 | 「계속 기다리고 있어. 춥네」 | 고침 |
| 「そうじゃん。分かった」 | 「그렇잖아. 알았어」 | 고침 |
| 「行くの？」 | 「가는 거야?」 | 고침 |
| 「わしは知っておる」 | 「나는 알고 있다」 | 고침 |
| 「速やかに報告せよ。待っている」 | 「신속하게 보고해라. 기다리고 있다」 | 유지 |
| 「これは私の剣である」 | 「이건 내 검이다」 | 유지 |
| 「今日は暑いですね。帰る」 | 「오늘은 덥네요. 돌아간다」 | 유지 |
| 「そうなんです……知らなかったでしょ？」 | 「그렇습니다……몰랐죠?」 | 고침 |
| 「知らなかったでしょ？」 | 「몰랐잖아?」 | 유지 |

## SPC-2 높이는 주어 뒤 (ら)れ는 높임이다

높이는 주어 뒤의 (ら)れ는 가능이나 수동이 아니라 높임으로 옮긴다(읽기를 정하는 순서는 GRM-10). 言われる는 구문에 따라 불리다, 말을 듣다,
말씀하시다 가운데 하나로 옮긴다. 높임으로 읽은 (ら)れ와 높임 동사(仰る, なさる, 召し上がる, お〜になる) 뒤의 ている,
てる는 -고 계시다로 옮기고 -으시고 있다로 옮기지 않는다. 결과 상태의 동사는 -아 계시다로, 亡くなる는 돌아가셨다로 옮긴다.

|---|---|---|

| 先生の言われる通りです。 | 선생님이 말씀하시는 대로입니다. | 고침 |
| 王子は天才と言われていた。 | 왕자는 천재라고 불렸다. | 고침 |
| バカと言われたことがある。 | 바보라는 말을 들었던 적이 있다. | 고침 |
| やっと来られた。 | 드디어 올 수 있었다. | 유지 |

## SPC-4 구어 축약은 다 쓴 꼴로 읽는다

입말에서 줄인 꼴은 다 쓴 꼴과 같은 뜻으로 옮긴다. て형 뒤 いく의 축약(てって, てか, てけ, てった), 명사 뒤 の를 ん으로
말한 꼴(ん中, んとこ), う로 끝나는 5단 동사의 과거와 て형을 う로 말한 꼴(言うた, 思うて)이다. 축약이 아닌 같은 표기,
곧 인용의 って와 ったら, 한 낱말 안의 ん(真ん中), ため 앞의 う는 그대로 읽는다. 멈추거나 기다리라는 부탁(やめて, 待って)은
가면서 하는 일이 아니므로 그 뒤의 ってね는 부탁을 옮기는 인용이다(やめてってね 그만두라고).

| 원문 | 출력 | 구분 |
|---|---|---|
| 「連れてって」 | 「데려가」 | 고침 |
| 「置いてかないで」 | 「두고 가지 마」 | 고침 |
| 頭ん中が真っ白だ。 | 머릿속이 새하얗다. | 고침 |
| 「最初に言うたやろ」 | 「처음에 말했지」 | 고침 |
| 「やめてって言ったのに」 | 「그만두라고 했는데」 | 유지 |
| 「やめてってね」 | 「그만두라고」 | 고침 |
| 「食べてってね」 | 「먹어 가」 | 유지 |
| 真ん中に置いた。 | 한가운데에 두었다. | 유지 |
| 救うために戦う。 | 구하기 위해 싸운다. | 유지 |

## SPC-5 문장 끝 ね는 약속과 감탄으로 나눠 옮긴다

동사 현재형 뒤의 ね는 발화가 거기서 끝나고(닫는 따옴표, 문장 끝 부호, 말줄임) 말하는 사람이 스스로 하겠다는
동작일 때만 -ㄹ게로 옮긴다. 상태, 느낌, 앎의 동사와 나타나거나 일어나는 일의 동사(月が出る, 始まる, 晴れる), 한국어로
형용사나 있다가 되는 동사, なる, 가능, ちゃう, くれる, 늘여 말한 ね(ねぇ), 말하는 사람이 아닌 주어 뒤는 -네로 옮기고, 홀로
서거나 상대를 부른 뒤의 やるね는 감탄 제법이네로 옮기고(お前、やるね 너, 제법이네), 말하는 사람이 주어로 나서면(私が, 僕は) -ㄹ게로 옮긴다. 말하는 사람이 하겠다는 出る는 나가다로 읽고(先に出るね 먼저 나갈게, 今日出るね 오늘 나갈게), 조사 없이 명사 바로 뒤의 出る는 그것이 나오는 일이며(涙出るね 눈물 나오네), 出す는 하는 동작이다(手紙を出すね 편지를 보낼게). -는군, -군요로 옮기지 않는다. ます 뒤의 ね도 같은 조건으로 나누되 해요체를 지켜 -ㄹ게요, -네요로 옮기고(淹れますね 끓일게요, 雨が降りますね 비가 오네요), 수동(また叱られますね 또 꾸중듣네요), 부르는 말이 아니면서 말하는 사람이 아닌 사람이 동사 바로 앞에 올 때(皆さん起きてきますね 여러분 일어나네요), 일어나는 일의 동사나 Nが V 뒤 くる(静まってきますね, お腹が空いてきますね), 양을 나타내는 부사 뒤 먹고 마시는 동사의 ますね(たくさん食べますね 많이 먹네요)는 -네요이며, です 뒤의 ね는 -네요이고, 높이지 않은 ね는 높이지
않는다(知っているね？ 알고 있네?).
동작 명사 뒤의 させていただきますね는 말하는 사람이 스스로 낮추어 하는 일이므로 -ㄹ게요로 옮긴다(説明させていただきますね 설명할게요).
물음표 앞이나 절 안(ね、, ねって)의 ね는 이 규칙으로 바꾸지 않는다. また明日ね처럼 다시 만날 때를 말하는 작별 인사는
인사말로 옮기고, 물음표 앞에서는 묻는 말로 둔다(また明日？ 또 내일?). 그 따옴표가 です, ます, ございます, ください로
높여 말하거나 높이는 사람을 쉼표와 함께 바로 앞에서 부르면 봬요로 옮긴다(先生、また来週 선생님, 다음 주에 봬요).
ますます의 ます와 お疲れさま의 さま는 높임이 아니다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 「先に行くね」 | 「먼저 갈게」 | 고침 |
| 「お茶淹れるね」 | 「차 끓일게」 | 고침 |
| 「違うね」 | 「다르네」 | 고침 |
| 「燃えるねぇ」 | 「불타네」 | 고침 |
| 「電車が来るね」 | 「전철이 오네」 | 고침 |

| 「先に出るね」 | 「먼저 나갈게」 | 고침 |

## SPC-6 ばいい로 묻는 말은 물음으로 옮긴다

ばいい는 -면 된다로 옮기되, 물음표 앞에서는 -면 돼?로, 의문사가 있는 문장 끝에서는 -면 좋을까로 옮긴다.
ばいいんだ는 물음표 앞에서 -면 돼?로, 물음표 없이 의문사 뒤에서 끝나면 -면 되지로 옮긴다.

## SPC-7 문장 끝 조사는 어미와 함께 옮긴다

문장 끝의 よ, ね, な, わ, ぞ, さ는 앞 어미와 함께 옮기고, 떨어뜨려 -다로 끝내지 않는다. ちゃう, ちゃった(じゃう,
ちまう) 뒤에서도 같다. よ와 ぞ는 해체(버렸어, 버릴 거야), ね와 な는 -네로 옮기고, ぜ는 書くぜ처럼
-다를 둔다. 따옴표 밖 지문에서도 같다.

## SPC-8 옛말투와 높임 계사는 앞말의 품사대로 활용한다

でござる, でござった, でございます, でござります 같은 옛말투와 높임 계사는 앞말이 형용동사이면 형용사로 활용한다
(조용하오, 괜찮습니다). 동사처럼 활용하거나(조용한다) 어간을 잘라 하다를 붙이지 않는다(괜합니다). 명사 뒤에서는
이다로 옮긴다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 静かでござる。 | 조용하오. | 고침 |
| 大丈夫でございます。 | 괜찮습니다. | 고침 |
| この刀は見事でござるな。 | 이 칼은 훌륭하구려. | 고침 |
| 先生でござる。 | 선생님이오. | 유지 |
| 静かでござるが、怖い。 | 조용하지만, 무섭다. | 유지 |

## SPC-9 옛말투의 부정과 추측은 뜻대로 옮긴다

かもしれぬ, やもしれぬ는 `-ㄹ지도 모른다`, とも知れぬ는 `-ㄹ지 모르는`이다. ませぬ 뒤에 ぞ, な가 붙어도 `-사옵니다`로
옮기고, 申し訳ありませぬ는 `죄송하옵니다`, いけませぬ는 `아니 되옵니다`다. 문장 끝의 べし는 `-야 한다`, 恐るべし는 `대단하다`다.

| いつ来るとも知れぬデコピン | 언제 올지 모르는 딱밤 | 고침 |
| 「申し訳ありませぬ！」 | 「죄송하옵니다!」 | 고침 |
| 「魔王を倒すべし！」 | 「마왕을 쓰러뜨려야 한다!」 | 고침 |

## SPC-10 권하는 ますか는 -ㄹ까요, 화면의 물음은 -시겠습니까다

문장을 끝내는 ますか는 권하는 표지가 있을 때만 그 일을 권하거나 하자고 하는 말로 보아 -ㄹ까요로 옮긴다. 표지는 확인 창의
동작(上書き, 保存, 削除, 使う처럼 확인 창이 묻는 일), にする로 고르는 말, 할 일을 묻는 말(どうしますか), 문장 앞의 권하는 말(さて, じゃあ, そろそろ, でも,
よかったら, 私達も, みんなで)이다. 『』나 《》 안의 시스템 메시지와 뒤에 と, 》, はい／いいえ 같은 답이 오는 화면의 물음은 읽는 사람의 뜻을 묻는
-시겠습니까, 높임 동사 뒤에서는 -겠습니까다. 표지가 없는 물음(日本語を話しますか)은 뜻을 바꾸지 않도록 -ㅂ니까로 둔다. 상태, 앎,
가능의 동사(ある, 思う, できる), 来る, ている, 높임으로 읽지 않은 される(GRM-10), くれる, 동사 앞에 따로 있는 의문사, は나 が로 든 주어, 2인칭 대명사,
버릇의 부사(毎日, いつも)가 있는 물음과 뒤에 느낌표가 오는 말도 -ㅂ니까로 둔다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 上書きしますか？ | 덮어쓰기할까요? | 고침 |
| 「じゃあ、そろそろ行きますか」 | 「그럼, 슬슬 갈까요」 | 고침 |
| 『チュートリアルを行いますか？』 | 『튜토리얼을 실시하시겠습니까?』 | 고침 |
| 「少しお休みになりますか？」 | 「조금 쉬시겠습니까?」 | 고침 |
| 日本語を話しますか？ | 일본어를 합니까? | 유지 |
| 「どこに行きますか？」 | 「어디에 갑니까?」 | 유지 |
| 「時間ありますか？」 | 「시간 있습니까?」 | 유지 |
| 毎日勉強しますか？ | 매일 공부합니까? | 유지 |

## SPC-11 높임 표현과 업무 편지의 굳은 말은 한국어의 굳은 높임으로 옮긴다

명사 뒤의 でいらっしゃる는 `이시다`, 형용동사 뒤에서는 `하시다`다. ご와 동작 명사에 の가 붙어 손님, 분, 여러분을 꾸미면
그 사람이 한 일이므로 `하신`(이용, 희망처럼 이어지는 일은 `하시는`)으로 옮기고, 그 뒤의 方는 `분`이다. 사람을 받는 조사 없이
を, 쉼표, 부탁의 말이 이어지는 の方는 ほう이므로 그대로 둔다(ご確認の方をお願いします). 동작 명사 뒤의
させていただきますね는 `-ㄹ게요`, 동사의 て형 뒤 させていただく는 `드리다`다. お時間をいただき, ご不明な点, 恐れ入りますが, お手数ですが, 取り急ぎ…まで 같은 업무 편지의
굳은 말은 한국어 편지에서 쓰는 말로 옮긴다.

| 원문 | 출력 | 구분 |
|---|---|---|
| ご予約のお客様でいらっしゃいますか | 예약하신 손님이십니까 | 고침 |
| ご利用のお客様 | 이용하시는 손님 | 고침 |
| ご希望の方はお申し出ください。 | 희망하시는 분은 신청해 주세요. | 고침 |
| 先生はお元気でいらっしゃいますか？ | 선생님은 건강하십니까? | 고침 |
| お手伝いさせていただきます | 도와 드리겠습니다 | 고침 |
| 貴重なお時間をいただきありがとうございます。 | 귀중한 시간을 내주셔서 감사합니다. | 고침 |
| ご不明な点があればご連絡ください。 | 궁금한 점이 있으면 연락해 주십시오. | 고침 |
| 取り急ぎご連絡まで。 | 우선 연락드립니다. | 고침 |
| 社長でいらっしゃいます。 | 사장이십니다. | 유지 |
| 予約のお客様 | 예약의 손님 | 유지 |

사례: `tests/rules/cases/cx-honorific-doer.tsv`, `tests/rules/cases/cx-humble-promise.tsv`,
`tests/rules/cases/lexical-polite-phrases.tsv`

## SPC-12 말한 것을 받는 って와 と는 인용으로 옮긴다

말하기, 생각하기, 묻기 동사와 쓰기, 부르기 동사(書く, 名乗る), 教える, 부탁이나 바람의 する 명사(希望する, お願いする)
바로 앞의 って는 화제의 (은)는이 아니라 인용의 (이)라고다. 문장을 끝맺는 꼴(종조사, 설명의 んだ, たい, 과거, から, ば)
바로 뒤의 と는 그 말을 받는 인용이라 뒤 동사가 말하기 동사가 아니어도 와, 과로 옮기지 않는다. 다로 끝나면 간접 인용
-다고로(그 문장에서 앞에 의문사가 있으면 묻는 말이라 -냐고로), 그 밖의 끝(-까, -군, -네, -니까, -면)은 직접 인용 하고로 잇고, 문장이 と로 끝나거나 と 뒤에 말줄임이 오면 덧붙이지 않는다. 말 전체로 쓰는
관용구나 감탄사(頑張れ, 気にするな, まさか) 뒤의 と도 하고다. ないと(해야 함), ますと(조건), 의지형의 양보(使おうと)와 과거나 たい 뒤에서 同じ, 同時, 一緒 같은
견주는 말 앞의 と(死んだと同時に)는 인용이 아니다. 게, 도록으로 끝난 말 뒤의 って는 그 말이 이미 부탁한 내용이라 옮기지 않는다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 人の少ない場所って希望したけど | 사람이 적은 장소라고 희망했지만 | 고침 |
| 「この神戸牛のステーキ、三万円って書いてあるんだけど……」 | 「이 고베규의 스테이크, 3만엔이라고 써 있는데……」 | 고침 |
| 熱いんじゃないかなぁと想像して放棄。 | 뜨겁지 않을까 하고 상상해 포기. | 고침 |
| 「曾孫の顔が見たいんだと」 | 「증손의 얼굴을 보고 싶다고」 | 고침 |
| 何があったんだと心配そうに | 무슨 일이 있었냐고 걱정스러운 듯이 | 고침 |
| 意地でも謝罪しないようにって教えたでしょ？ | 무슨 일이 있어도 사죄하지 않도록 가르쳤잖아? | 고침 |
| とても優秀だからと求婚したけど断られた | 무척 우수하니까 하고 청혼했지만 거절당했다 | 고침 |
| 気にするなと声を掛けておいた。 | 신경 쓰지 마 하고 말을 걸어 두었다. | 고침 |
| 猫って可愛い。 | 고양이는 귀엽다. | 유지 |
| 来るかなと待っていた。 | 올까 하고 기다리고 있었다. | 유지 |
| 友達と遊んだ。 | 친구와 놀았다. | 유지 |
| そうだろうと思った。 | 그럴 것이라고 생각했다. | 유지 |
| 頂ければと……ありがとう存じます。 | 주시면……감사합니다. | 고침 |

현재: ないとと(作らないとと 만들지 않으면과)와 명사 앞의 って(「救助訓練実施中」って返事 은 대답)는 아직 따르지 않는다.
