# 말투

## SPC-1 따옴표 안 말투는 원문의 표지를 따른다

「」 안의 기본 말투는 -다로 끝나는 strict이고, soft는 옵션으로만 켠다. 원문 대사에 반말 표지(よ, ね, わ, じゃん,
ちゃう, てる, 반말 의문)가 있으면 반말로, 예스러운 말투나 거만한 말투의 표지(ておる, じゃ, ぬ, せよ, である)가
있으면 -다로, です와 ます는 높임말로 옮긴다. です, ます, ください로 높여 말한 따옴표 안의 でしょ는 그 따옴표에
반말 표지가 없으면 높임말로 동의를 구한다(몰랐죠?, 높죠?). なさい만 있는 따옴표는 높임말이 아니다. っす는
아랫사람의 가벼운 높임이므로 해요체로 옮긴다. 표지가 없으면 기본 말투를 바꾸지 않는다. 말하는 사람을 추적해
말투를 정하지 않는다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 「違う。そうじゃないよ」 | 「아니야. 그렇지 않아」 | 고침 |
| 「ずっと待ってる。寒いね」 | 「계속 기다리고 있어. 춥네」 | 고침 |
| 「そうじゃん。分かった」 | 「그렇잖아. 알았어」 | 고침 |
| 「行くの？」 | 「가는 거야?」 | 고침 |
| 「わしは知っておる」 | 「나는 알고 있다」 | 고침 |
| 「速やかに報告せよ。待っている」 | 「신속하게 보고해라. 기다리고 있다」 | 유지 |
| 「これは私の剣である」 | 「이건 내 검이다」 | 유지 |
| 「今日は暑いですね。帰る」 | 「오늘은 덥네요. 돌아간다」 | 유지 |
| 「そうなんです……知らなかったでしょ？」 | 「그렇습니다……몰랐죠?」 | 고침 |
| 「知らなかったでしょ？」 | 「몰랐잖아?」 | 유지 |
| 「了解っす」 | 「알겠어요」 | 유지 |
| 「そうっすね」 | 「그렇네요」 | 유지 |
| 「明日、海に行く」 | 「내일, 바다에 간다」 | 유지 |
| 「余計なことを言うな。分かっているのだ」 | 「쓸데없는 말을 하지 마. 알고 있다」 | 유지 |

`tests/rules/cases/rules-speech.tsv`

## SPC-2 높이는 주어 뒤 (ら)れ는 높임이다

높이는 주어 뒤의 (ら)れ는 가능이나 수동이 아니라 높임으로 옮긴다. 言われる는 구문에 따라 불리다, 말을 듣다,
말씀하시다 가운데 하나로 옮긴다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 先生が来られた。 | 선생님이 오셨다. | 고침 |
| 陛下は手紙を書かれている。 | 폐하는 편지를 쓰고 계신다. | 고침 |
| 先生の言われる通りです。 | 선생님이 말씀하시는 대로입니다. | 고침 |
| 王子は天才と言われていた。 | 왕자는 천재라고 불렸다. | 고침 |
| バカと言われたことがある。 | 바보라는 말을 들었던 적이 있다. | 고침 |
| やっと来られた。 | 드디어 올 수 있었다. | 유지 |
| 手紙が書かれている。 | 편지가 쓰여져 있다. | 유지 |
| 言われた通りにした。 | 들은 대로 했다. | 유지 |

사례: `tests/rules/cases/honorific-respectful-passive.tsv`, `tests/rules/cases/say-passive.tsv`

## SPC-4 구어 축약은 다 쓴 꼴로 읽는다

입말에서 줄인 꼴은 다 쓴 꼴과 같은 뜻으로 옮긴다. て형 뒤 いく의 축약(てって, てか, てけ, てった), 명사 뒤 の를 ん으로
말한 꼴(ん中, んとこ), う로 끝나는 5단 동사의 과거와 て형을 う로 말한 꼴(言うた, 思うて)이다. 축약이 아닌 같은 표기,
곧 인용의 って와 ったら, 한 낱말 안의 ん(真ん中), ため 앞의 う는 그대로 읽는다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 「連れてって」 | 「데려가」 | 고침 |
| 「置いてかないで」 | 「두고 가지 마」 | 고침 |
| 頭ん中が真っ白だ。 | 머릿속이 새하얗다. | 고침 |
| 「最初に言うたやろ」 | 「처음에 말했지」 | 고침 |
| 「やめてって言ったのに」 | 「그만두라고 했는데」 | 유지 |
| 真ん中に置いた。 | 한가운데에 두었다. | 유지 |
| 救うために戦う。 | 구하기 위해 싸운다. | 유지 |

사례: `tests/rules/cases/spoken-contractions.tsv`

## SPC-5 문장 끝 ね는 약속과 감탄으로 나눠 옮긴다

동사 현재형 뒤 문장 끝의 ね는 말하는 사람이 하겠다는 약속이면 -ㄹ게로, 보고 느낀 것이면 -네로 옮긴다. 상태, 느낌,
앎의 동사, 한국어로 형용사나 있다가 되는 동사, なる, 가능, ちゃう, くれる, 늘여 말한 ね(ねぇ), 말하는 사람이 아닌
주어 뒤에서는 -네이고, 그 밖의 동작은
-ㄹ게다. -는군, -군요로 옮기지 않는다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 「先に行くね」 | 「먼저 갈게」 | 고침 |
| 「お茶淹れるね」 | 「차 끓일게」 | 고침 |
| 「違うね」 | 「다르네」 | 고침 |
| 「燃えるねぇ」 | 「불타네」 | 고침 |
| 「電車が来るね」 | 「전철이 오네」 | 고침 |
| 「食べたね」 | 「먹었네」 | 유지 |

사례: `tests/rules/cases/sentence-final-ne.tsv`
