# 출력 점검 (0.8)

0.8의 점검(QE)은 일본어 절이 요구하는 것을 한국어가 실현했는지 보는 규칙이다. 일본어 쪽은 L 단계 규칙이 정한 절 자질(극성,
부정의 기능, 문장 힘, 태, 수수, 경어, 양태, 접속)이고, 한국어 쪽은 문장마다 읽은 사실(부정어, -ㄹ 수 없다, -잖아, -어야 하다,
-지 마, 물음, -시-, -어 받다, 숫자, 이름)이다. 점검은 줄에 표시만 하고 출력을 바꾸지 않는다. 학습한 표(부정 기능 분류기, 태
분류기, 사람 번역에서 센 이름 목록)는 읽지 않는다.

규칙 표: `poc08/critical/data/check.tsv`(열 `spec`), 사례: `poc08/critical/data/check.cases.tsv`(`qe/cases.py`). 한 절에 같은
규칙 id의 행이 여럿 맞으면 조건 원자가 가장 많은 행이 정한다(예외는 같은 id에 원자를 더한 행이다).

측정(뜻 뒤집힘 모음 592항목, 0.7.6 출력): 실패 180 중 37을 표시(재현율 20.6%), 표시한 53 중 37이 실패(정밀도 69.8%). 학습한
표를 읽던 판은 26.1% / 62.7%였다. 줄어든 재현율은 학습 분류기가 주던 부정 기능(확인 의문, 권유, 설명)과 れる/られる의 태다.
L의 부정 기능 규칙과 T의 태 규칙이 그 자질을 정하면 같은 행으로 되찾는다.

## CHK-1 부정은 부정으로 쓴다

부정 절(pol=neg)이 있는 문장에는 부정어(안, 않다, 못, 없다, 아니다, 모르다), -ㄹ 수 없다, -잖아 또는 -어야 하다가 있어야 한다.
ないうちに는 -기 전에도 된다(`neg.before-1`).

| 원문 | 출력 | 구분 |
|---|---|---|
| 今出てくれば俺たちは手出しはせん！ | 지금 나오면 우리는 손찌검! | 표시 |
| 今出てくれば俺たちは手出しはせん！ | 지금 나오면 우리는 손대지 않아! | 통과 |
| 冷めないうちに召し上がれ！ | 식기 전에 드세요! | 통과 |

## CHK-2 가능의 부정은 -ㄹ 수 없다나 못으로 쓴다

부정 기능이 가능 부정(行けない, 隠せない)이고 れる/られる가 없는 절은 -ㄹ 수 없다나 못이 있어야 한다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 憂鬱な気分を隠せないまま | 우울한 기분을 숨기지 없는 채 | 표시 |
| 憂鬱な気分を隠せないまま | 우울한 기분을 숨길 수 없는 채 | 통과 |

## CHK-3 금지는 금지로 쓴다

부정 기능이 금지이거나 문장 힘이 금지인 절(てはならない, するな)은 -지 마, -면 안 되다가 있어야 한다. なくてもいい(양태 may)는
금지가 아니라 "안 해도 된다"이므로 부정어만 있으면 된다(`neg.permit-1`).

| 원문 | 출력 | 구분 |
|---|---|---|
| この悪魔の甘言に耳を傾けてはなりません | 이 악마의 감언에 귀를 기울여 되지 않습니다 | 표시 |
| それに触るな！ | 그거 만지지 마! | 통과 |
| そう落ち込まなくてもいいですよ。 | 그렇게 낙담하지 않아도 괜찮아요. | 통과 |

## CHK-4 의무는 -어야 하다로 쓴다

부정 기능이 의무이거나 양태가 must인 절(なければならない, ねばならん)은 -어야 하다/되다, -야지가 있어야 한다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 仕事も探さねばならんし。 | 일도 찾지 않으면 되지 않아 해. | 표시 |
| 仕事も探さねばならんし。 | 일도 찾아야 하고. | 통과 |

## CHK-5 반어의 じゃない는 평서 부정으로 쓰지 않는다

부정 기능이 반어(んじゃねぇ, ではないか)인 절이 있고 부정 절이 없는 문장은 평서 부정(-는 것이 아니야)이 되면 안 된다. -잖아,
물음, 금지(-지 마)는 된다.

| 원문 | 출력 | 구분 |
|---|---|---|
| テメェ笑ってんじゃねぇ！！ | 네놈 웃고 있는 것이 아니야!! | 표시 |
| テメェ笑ってんじゃねぇ！！ | 네놈 웃지 마!! | 통과 |

## CHK-6 이중 부정은 긍정이다

부정 기능이 이중 부정(ないわけではない)이면 부정어 하나뿐인 평서 부정은 뜻을 뒤집는다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 行きたくないわけではない。 | 가고 싶은 것은 아니다. | 표시 |
| 行きたくないわけではない。 | 가고 싶지 않은 것은 아니다. | 통과 |

## CHK-7 옛 의지의 ん은 부정이 아니다

부정 기능이 옛 의지(貫かんとする)면 부정어를 쓰지 않는다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 鋭く意志を貫かんとする | 날카롭게 의지를 관철하지 않는다 | 표시 |
| 鋭く意志を貫かんとする | 날카롭게 의지를 관철하려 한다 | 통과 |

## CHK-8 물음은 물음으로 쓴다

문장 힘이 물음이고 ？로 끝나는 문장의 마지막 절은 한국어도 물음(물음 어미나 ?)이어야 한다. 반어는 뺀다.

| 원문 | 출력 | 구분 |
|---|---|---|
| お前、本当にそれでいいのか？ | 너, 정말로 그걸로 된다. | 표시 |
| お前、本当にそれでいいのか？ | 너, 정말로 그걸로 괜찮아? | 통과 |

## CHK-9 명령은 가능으로 쓰지 않는다

문장을 맺는 명령 절은 -ㄹ 수 있다/없다로 쓰지 않는다. 같은 문장에 가능 절이 있으면 뺀다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 早く行け！ | 빨리 갈 수 있어! | 표시 |
| 早く行け！ | 빨리 가! | 통과 |

## CHK-10 높임 술어는 -시-로 쓴다

경어가 존경(sonkei)인 절은 명령, 요청, 금지가 아니면 -시-나 높임 동사가 있어야 한다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 雇って下さっただけでも十分です。 | 고용해 준 것만으로도 충분합니다. | 표시 |
| 雇って下さっただけでも十分です。 | 고용해 주신 것만으로도 충분합니다. | 통과 |

## CHK-11 てもらう를 -어 받다로 옮기지 않는다

수수가 받음(てもらう)인 절은 -어 받다로 쓰지 않는다.

| 원문 | 출력 | 구분 |
|---|---|---|
| お姉様はあまり公の場に出して貰えなかった。 | 누님은 그다지 국가 기관에 내 받을 수 없었다. | 표시 |
| お姉様はあまり公の場に出して貰えなかった。 | 누님은 공식 자리에 별로 나가지 못했다. | 통과 |

## CHK-12 숫자는 빠뜨리지 않는다

원문의 숫자(아라비아 숫자, 한자 숫자)는 모두 한국어에 있어야 한다(숫자, 한자어 수, 고유어 수).

| 원문 | 출력 | 구분 |
|---|---|---|
| 二一世紀の科学技術 | 2 일세기의 과학기술 | 표시 |
| 二一世紀の科学技術 | 21세기 과학기술 | 통과 |

## CHK-13 이름은 빠뜨리지 않는다

분석기가 사람이나 땅 이름으로 읽은 말은 음역되어 한국어에 있어야 한다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 秀吉は自分の手を見た。 | 히데키치는 자신의 손을 보았다. | 표시 |
| 秀吉は自分の手を見た。 | 히데요시는 자신의 손을 보았다. | 통과 |
