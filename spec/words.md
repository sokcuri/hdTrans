# 낱말

## LEX-1 가타카나 외래어는 외래어로 옮긴다

가타카나 외래어는 원어 발음을 표준 외래어 표기법으로 적은 외래어로 옮긴다. 한국어가 보통 고유어나 한자어를 쓰는
말만 그 말로 옮긴다. 일본어 가타카나 읽기(데프로이)로 적지 않는다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 本番環境にデプロイした。 | 운영 환경에 디플로이했다. | 고침 |
| リポジトリにプッシュした。 | 리포지토리에 푸시했다. | 고침 |
| プッシュしてからプルリクエストを送る。 | 푸시하고 나서 풀 리퀘스트를 보낸다. | 고침 |
| イシューを立てる。 | 이슈를 오픈한다. | 고침 |
| 木を切るためにチェーンソーを使う。 | 나무를 자르기 위해 전기톱을 쓴다. | 고침 |
| ドアを閉めた。 | 문을 닫았다. | 유지 |
| ガスマスクが必要だ。 | 방독면이 필요하다. | 유지 |
| ファイルをダウンロードした。 | 파일을 다운로드했다. | 유지 |

사례: `tests/rules/cases/it-vocabulary.tsv`, `tests/rules/cases/loanword-spellings.tsv`,
`tests/rules/cases/rules-words.tsv`

## LEX-3 사전 뜻풀이는 짧은 한국어 낱말이나 구다

사전 행의 번역은 짧은 한국어 낱말이나 구로 쓴다. 풀이하는 정의, 괄호 속 영어, 뜻 목록, 옮기지 않은 영어를 넣지

## LEX-4 이름 읽기는 명사로 읽히는 낱말을 덮지 않는다

문맥이 일반 명사로 읽는 낱말에는 인명, 지명 읽기를 쓰지 않는다. 이름은 호칭, 가운뎃점으로 이은 이름, 같은 문서의
다른 쓰임 같은 단서로 알아보고, 뒤 동사와의 어울림으로 정하지 않는다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 王子と会った時の私はまだ子供だった。 | 왕자와 만났을 때의 나는 아직 아이였다. | 고침 |
| 高原さんが来た。 | 타카하라 씨가 왔다. | 유지 |
| ジョン・スミスが来た。 | 존 스미스가 왔다. | 유지 |
| 「さすが、お姫様を守るナイトだね」 | 「역시, 공주님을 지키는 나이트구나」 | 유지 |
| 星に願いを込めた。 | 별에 소원을 담았다. | 고침 |
| ポケットの中に入っている。 | 주머니 속에 들어가 있다. | 유지 |

조사(を, に, へ, は)로 이은 구 모양의 이름(작품 이름)은 앞뒤가 문장과 떨어져 있을 때만 이름으로 읽는다.

사례: `tests/rules/cases/names-common-nouns.tsv`, `tests/rules/cases/names-polite-cues.tsv`,
`tests/rules/cases/names-chain-parts.tsv`, `tests/rules/cases/names-glosses.tsv`,
`tests/rules/cases/names-phrase-titles.tsv`

## LEX-5 가타카나로 쓴 일반 낱말은 그 낱말로 읽는다

대명사, 감탄사처럼 히라가나나 한자로 쓰는 낱말을 가타카나로 쓴 것은 그 낱말과 같게 읽는다. 소리대로 적지 않는다.
낱말의 히라가나 어미는 소리대로 적는 가타카나 구간에 넣지 않는다. 다만 한 문장에 가타카나로 쓴 1인칭 대명사와 다른
표기의 1인칭 대명사가 함께 나오면(ワタシと私) 가타카나 쪽은 따로 선 다른 나이므로 소리대로 적는다. 말줄임표 바로 뒤에서
고쳐 말한 대명사(ワタシが…私が)는 다른 나가 아니다.

| 원문 | 출력 | 구분 |
|---|---|---|
| ワタシはここにいるよ | 나는 여기에 있어 | 고침 |
| ゴメンな。 | 미안해. | 고침 |
| リアルなティアーズ | 리얼한 티아즈 | 고침 |
| そんなのはゴメンだ。 | 그런 것은 싫다. | 유지 |
| そんなのゴメンよ。 | 그런 것 싫어. | 유지 |
| ワタシと私が融合して | 와타시와 내가 융합해 | 고침 |
| ワタシは帰る。私は残る。 | 나는 돌아간다. 나는 남는다. | 유지 |

사례: `tests/rules/cases/lexical-katakana-spellings.tsv`, `tests/rules/cases/cx-second-self.tsv`

## LEX-7 の中는 담는 것이면 안, 그 속에 있는 것이면 속이다

상자, 방처럼 담는 것 뒤의 中은 `안`, 기억, 밤, 정적처럼 그 속에 있는 매질, 때, 상태 뒤의 中은 `속`이다. 무리 가운데
고르는 中은 `중`이다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 記憶の中に残る。 | 기억 속에 남는다. | 고침 |
| 静寂の中で感じた。 | 정적 속에서 느꼈다. | 고침 |
| 箱の中に入れる。 | 상자 안에 넣는다. | 유지 |
| 人の中で一番強い。 | 사람 중에서 제일 강하다. | 유지 |

사례: `tests/rules/cases/pass-naka-sok.tsv`, `tests/rules/cases/naka-inside-mass.tsv`

## LEX-8 명사 뒤의 なんて, なんか는 `같은 건`이다

명사나 `명사のこと` 뒤에서 낮추어 말하는 なんて, なんか는 `같은 건`으로 옮긴다. のこと는 따로 옮기지 않고, 때를 나타내는
명사 뒤에서만 `의 일`로 옮긴다.

| 원문 | 출력 | 구분 |
|---|---|---|
| あたしのことなんて | 나 같은 건 | 고침 |
| 昨日のことなんて覚えてない | 어제의 일 같은 건 기억하지 못한다 | 고침 |
| 夢なんて忘れて。 | 꿈 같은 건 잊어. | 유지 |

## LEX-9 뒤 동사로 이어지는 に向けて, に向かって는 `(을)를 향해`다

に向けて, に向かって가 뒤 동사의 방향을 나타내면 앞말이 장소든 사람이든 `(을)를 향해`로 옮긴다. 문장을 끝내는 向かう(가는
곳)와 向けている처럼 보조 동사가 붙은 것은 `(으)로 향하다`로 둔다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 進行方向を地球に向け加速していた。 | 진행 방향을 지구를 향해 가속하고 있었다. | 고침 |
| 駅に向かって走り出した。 | 역을 향해 달리기 시작했다. | 고침 |
| 銃口を男に向けて撃った。 | 총구를 남자를 향해 쏘았다. | 고침 |
| 学校に向かった。 | 학교로 향했다. | 유지 |

사례: `tests/rules/cases/cx-toward-adverbial.tsv`

## LEX-10 맡기는 동사 앞의 後は는 `나머지는`이다

頼む, 任せる처럼 일을 맡기는 동사 앞의 後は, 後を는 남은 일이므로 말줄임이나 이름 뒤에서도 `나머지는`, `나머지를`로 옮긴다.
の나 동사 뒤의 後는 그 일 뒤의 때다(食事の後は 식사 뒤는).

| 원문 | 출력 | 구분 |
|---|---|---|
| 総員退去！ あとは…後は頼んだわ！ | 총원 퇴거! 나머지는…나머지는 부탁했어! | 고침 |
| 後を頼む。 | 나머지를 부탁한다. | 고침 |
| 後は寝るだけだ。 | 나머지는 잘 뿐이다. | 유지 |
| 食事の後は任せた。 | 식사 뒤는 맡겼다. | 유지 |

사례: `tests/rules/cases/cx-rest-entrusted.tsv`

## LEX-12 사전에 있는 복합 명사는 앞부분 명사와 나머지로 나누지 않는다

사전에 긴 명사 행(治験薬)이 있으면 그 앞부분 명사 행(治験)과 나머지(薬)로 나누어 읽지 않고 긴 행으로 읽는다. 명사 행의
품사 첫 글자(I, K, N)는 고르는 순서를 정하지 않는다. 다음은 나누어 읽는다.

- 히라가나로 끝나는 행 뒤에 조사, 문장 부호, 명사 뒤의 이다 활용(だ, です)이나 끝 조사(か, よ)가 아닌 가나나 한자가 이어져
  동사의 활용이 될 때(経験あり + ます, 経験あり + そうだ, 追って書き + 込んで).
- 앞부분이 구, 기능어 행일 때(ぶり, 二人).

| 원문 | 출력 | 구분 |
|---|---|---|
| 治験薬を飲んだ。 | 임상 시험약을 먹었다. | 고침 |
| 俺は、最後の気力を振り絞って、最重要事項を伝えた。 | 나는, 마지막 기력을 쥐어짜고, 가장 중요한 사항을 전했다. | 고침 |
| 少しは経験ありますよぉ。 | 조금은 경험 있어요. | 유지 |
| 二日ぶりに会った。 | 이틀만에 만났다. | 유지 |

사례: `tests/rules/cases/compound-noun-rows.tsv`

## LEX-13 같은 말의 다른 표기는 같게 읽는다

문법으로 쓰는 말을 한자로 쓴 것(程, 位, 等, 為, 迄)은 가나로 쓴 것(ほど, くらい, など, ため, まで)과 같게 읽는다.
서술어의 끝이나 の 뒤에서 가나로 쓴 とき는 時와 같게 읽는다. 그 표기가 다른 낱말의 일부이거나 다른 뜻(神の位, 為す,
それ等)이면 그대로 둔다. それぐらい, これぐらい처럼 지시어에 붙은 ぐらい는 くらい 표기와 같은 낱말로 읽는다.
事, 物, 所는 일, 물건, 곳으로 읽히는 뜻이 따로 있어서 こと, もの, ところ와 합치지 않는다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 呉で朽ち果てる迄、戦うつもりだ。 | 오로 헛되이 죽을 때까지, 싸울 생각이다. | 고침 |
| プライドが高かった為、 | 프라이드가 높았기 때문에, | 고침 |
| 追い詰められてるときは | 몰리고 있을 때는 | 고침 |
| それぐらいに近い。 | 그 정도로 가깝다. | 고침 |
| 上手くいった。 | 잘 되었다. | 고침 |
| 身の程を知れ。 | 분수를 알아라. | 유지 |
| 何を為そうとしているのですか？ | 무엇을 하려 하고 있습니까? | 유지 |

사례: `tests/rules/cases/spelling-variants.tsv`, `tests/rules/cases/pass-verb-senses.tsv`

## LEX-16 접미사 읽기는 명사 뒤에서만 쓴다

명사에 붙은 한자의 접미사 읽기(海 해, 様 님, 級 급)는 앞말이 명사일 때만 쓴다. 의성어, 감탄사처럼 한글로 옮겨진
앞말 뒤의 한자는 제 낱말로 옮기고, 의태어에도 붙는 접미사(型 형)만 접미사로 읽는다. 頭는 명사에 붙어도 머리로 옮기고,
굳은 복합어(旗頭 우두머리, 筆頭 필두)는 그 낱말로 옮긴다.

| あぁ…水が入ってきた。 | 아아…물이 들어 왔다. | 고침 |
| 白髪頭の老人が座っていた。 | 백발머리의 노인이 앉아 있었다. | 고침 |
| 牛が三頭いる。 | 소가 세 마리 있다. | 유지 |
| 先頭に立つ。 | 선두에 선다. | 유지 |
| マリア様が来た。 | 마리아님이 왔다. | 유지 |
| バルト海の船。 | 발트해의 배. | 유지 |
| グルグル型のお香を焚きましょう。 | 빙글빙글 형의 향을 핍시다. | 유지 |
| 越前国旗頭 | 에치젠국 우두머리 | 고침 |
| 国旗を掲げる。 | 국기를 게양한다. | 유지 |

## LEX-17 말머리의 と、와 そうだ는 감탄사다

대사 안에서 문장 첫머리나 문장 끝, 말줄임표 뒤에 오는 と、는 인용 조사가 아니라 말을 돌리는 감탄사라 아,로 옮긴다.
뒤가 말하기, 생각하기 동사이면 앞말을 받는 인용으로 두고, 지문의 줄 첫머리 と、는 앞 대사를 받는 인용으로 둔다. 다만
감탄사 そうだ 앞의 と、와 말머리 っと、는 지문에서도 아,다.
쉼이나 문장 끝 앞에 홀로 선 そうだ는 감탄사다. 알아차리거나 떠올리는 감탄사(あ, あっ)와 말머리 と、 뒤, 말이
이어지는 말줄임표 뒤(같은 문장에서, 또는 대사 안의 ！나 ？ 뒤 다음 문장으로 이어질 때)에서는 생각난 것을 알리는 맞다로, 문장 첫머리, 문장 끝 부호 뒤, 홀로 선 말줄임표 뒤, ああ나
うん 같은 첫 감탄사 뒤에서는 맞장구인 그래로 옮긴다. 동사 뒤의 そうだ(전언)와 문장 가운데의 そうだ는 그대로 둔다.

|---|---|---|

## LEX-18 형용사 く 뒤의 なんか, なんて, など와 ない는 힘준 부정이다

い형용사의 く 뒤에 なんか, なんて, など가 오고 부정 ない가 이어지면 `-지도 않다`로 옮긴다. なんか 뒤에서 ない를 말하지
않고 끊어도 같다. 동사(なる, する, 言う)가 이어지는 なんか, など는 `-게는`이다.

현재: 따름. 쉼표 뒤의 ない(嬉しくなんか、ない)와 ねえ, ねー로 줄인 부정은 아직 따르지 않는다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 嬉しくなんかないし | 기쁘지도 않고 | 고침 |
| 「優しくなんかないよ……」 | 「다정하지도 않아……」 | 고침 |
| 眠くなんかありません！ | 졸리지도 않습니다! | 고침 |
| 「ははは、怖くなんてないさ」 | 「하하하, 무섭지도 않아」 | 고침 |
| 別に嬉しくなんか！ | 별로 기쁘지도! | 고침 |
| 「別に仲良くなんかなってないぞ」 | 「별로 사이 좋게는 돼 있지 않아」 | 고침 |
| 強くなど言わない | 강하게는 말하지 않는다 | 고침 |
| 嬉しくはない | 기쁘지는 않다 | 유지 |
| こんなに嬉しくなんて | 이렇게 기쁘다니 | 유지 |

## LEX-19 破る는 목적어의 부류로 뜻을 고른다

破る는 を로 받은 목적어의 뜻으로 옮긴다. 법, 규칙, 약속, 명령, 협정은 어기다, 종이, 편지, 옷은 찢다, 벽, 유리, 침묵,
기록, 껍질, 틀은 깨다, 사람, 단체, 상대는 물리치다다. 목적어와 破る 사이에 부사나 수동의 행위자(弟に)가 와도 같다.
수동의 행위자 に는 목적어가 아니므로 물리치다의 근거가 되지 않는다. 見破る는 간파하다다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 「私の言いつけを破って、ゲーム大会で小細工をするようになったんです」 | 「제 명령을 어기고, 게임 대회에서 세공을 하게 됐습니다」 | 고침 |
| 最後の最後に、また、私の命令を破るようですね？ | 마지막의 마지막에, 또, 제 명령을 어기는 것 같네요? | 고침 |
| 他の陣営が紳士協定を破って場所取りを…… | 다른 진영이 신사 협정을 어겨 장소 잡기를…… | 고침 |
| 大事な手紙を弟に破られてしまった。 | 소중한 편지를 남동생이 찢어 버렸다. | 고침 |
| でも選挙で戦い、対立候補を破ることが私の将来にとって大切な気がします | 하지만 선거에서 싸워, 대립 후보를 물리치는 것이 제 장래에 있어 중요한 생각이 듭니다 | 고침 |
| サルたちが沈黙を破った。 | 원숭이들이 침묵을 깨었다. | 유지 |
| 手紙を破った。 | 편지를 찢었다. | 유지 |
| 敵を破った。 | 적을 물리쳤다. | 유지 |
| ふふふ……よくぞ見破った | 후후후……잘 간파했다 | 유지 |
