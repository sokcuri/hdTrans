# 낱말

## LEX-1 가타카나 외래어는 외래어로 옮긴다

가타카나 외래어는 원어 발음을 표준 외래어 표기법으로 적은 외래어로 옮긴다. 한국어가 보통 고유어나 한자어를 쓰는
말만 그 말로 옮긴다. 일본어 가타카나 읽기(데프로이)로 적지 않는다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 本番環境にデプロイした。 | 운영 환경에 디플로이했다. | 고침 |
| リポジトリにプッシュした。 | 리포지토리에 푸시했다. | 고침 |
| プッシュしてからプルリクエストを送る。 | 푸시하고 나서 풀 리퀘스트를 보낸다. | 고침 |
| イシューを立てる。 | 이슈를 오픈한다. | 고침 |
| 木を切るためにチェーンソーを使う。 | 나무를 자르기 위해 전기톱을 쓴다. | 고침 |
| ドアを閉めた。 | 문을 닫았다. | 유지 |
| ガスマスクが必要だ。 | 방독면이 필요하다. | 유지 |
| ファイルをダウンロードした。 | 파일을 다운로드했다. | 유지 |

사례: `tests/rules/cases/it-vocabulary.tsv`, `tests/rules/cases/loanword-spellings.tsv`,
`tests/rules/cases/rules-words.tsv`

## LEX-2 외래어 표기는 쓰임으로 고른다

같은 외래어를 적는 표기가 여럿이면 많이 쓰이는 표기를 쓴다.

| 원문 | 출력 | 구분 |
|---|---|---|
| リポジトリをクローンしてください。 | 리포지토리를 클론해 주세요. | 고침 |
| ディレクトリを移動する。 | 디렉터리를 이동한다. | 고침 |
| メッセージを送った。 | 메시지를 보냈다. | 유지 |

사례: `tests/rules/cases/it-vocabulary.tsv`, `tests/rules/cases/rules-words.tsv`

## LEX-3 사전 뜻풀이는 짧은 한국어 낱말이나 구다

사전 행의 번역은 짧은 한국어 낱말이나 구로 쓴다. 풀이하는 정의, 괄호 속 영어, 뜻 목록, 옮기지 않은 영어를 넣지
않는다.

| 원문 | 출력 | 구분 |
|---|---|---|
| これが三種の神器だ。 | 이것이 삼종 신기다. | 고침 |
| 両チームの初顔合わせとなった。 | 양팀의 첫 대면이 되었다. | 고침 |
| ちょっと野暮用で出かける。 | 조금 볼일로 나간다. | 고침 |
| 黒枠の眼鏡をかけた男。 | 검은 테두리의 안경을 쓴 남자. | 고침 |

사례: `tests/rules/cases/short-terms-for-glosses.tsv`, `tests/rules/cases/glosses-everyday-words.tsv`

## LEX-4 이름 읽기는 명사로 읽히는 낱말을 덮지 않는다

문맥이 일반 명사로 읽는 낱말에는 인명, 지명 읽기를 쓰지 않는다. 이름은 호칭, 가운뎃점으로 이은 이름, 같은 문서의
다른 쓰임 같은 단서로 알아보고, 뒤 동사와의 어울림으로 정하지 않는다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 王子と会った時の私はまだ子供だった。 | 왕자와 만났을 때의 나는 아직 아이였다. | 고침 |
| 高原さんが来た。 | 타카하라 씨가 왔다. | 유지 |
| ジョン・スミスが来た。 | 존 스미스가 왔다. | 유지 |
| 「さすが、お姫様を守るナイトだね」 | 「역시, 공주님을 지키는 나이트구나」 | 유지 |

사례: `tests/rules/cases/names-common-nouns.tsv`, `tests/rules/cases/names-polite-cues.tsv`,
`tests/rules/cases/names-chain-parts.tsv`, `tests/rules/cases/names-glosses.tsv`
