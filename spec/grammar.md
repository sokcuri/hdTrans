# 문법

## GRM-1 사역 수동의 に 앞 사람은 `때문에`다

사역 수동(させられる, 読まされる, 待たされる)의 に 앞에 사람이 오면, 그 사람은 시킨 사람이므로 `때문에`로 옮긴다.
`에게`로 옮겨 시킨 사람과 한 사람을 뒤섞지 않는다. 동사는 `-게 되다`나 그 동사 그대로 옮긴다. 묻거나(か) 부정하는
(ない, ません) 꼴과 바라는 꼴(たい)은 가능으로 읽으므로 바꾸지 않는다. 사람이 아닌 말 뒤의 に(サマコンには, 気持ちに)와
사역(食べさせた)의 に는 그대로다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 母に野菜を食べさせられた。 | 어머니 때문에 야채를 먹었다. | 고침 |
| 母に本を読まされた。 | 어머니 때문에 책을 읽게 되었다. | 고침 |
| 彼に一時間も待たされた。 | 그 때문에 1시간이나 기다리게 되었다. | 고침 |
| 後輩にはいつも苦労させられて…… | 후배 때문에 언제나 고생 당해…… | 고침 |
| 母が子供に野菜を食べさせた。 | 어머니가 아이에게 야채를 먹였다. | 유지 |
| 野菜を食べさせられた。 | 야채를 먹었다. | 유지 |
| こんな汚れ仕事、あの子にはやらせられないもの。 | 이런 더러운 일, 그 아이에게는 시킬 수 없는 것. | 유지 |

사례: `tests/rules/cases/grammar-causative-passive.tsv`

## GRM-2 を 목적어가 있는 수동의 に 앞 사람은 주어다

수동 동사 앞 절에 を 목적어가 있고 に 앞에 사람이 오면, 그 사람이 한 일로 보아 능동으로 옮긴다. に는 `(이)가`이고
대명사는 주어 꼴(내가, 네가)이다. 한국어에 따로 수동 낱말이 있는 동사(칭찬받다, 인정받다, 야단맞다)와 목적어가 없는
수동(母に叱られた), に 앞에 が 주어가 있는 절, 바라는 꼴(たい)은 수동 그대로다. 받는 사람을 に로 받는 동사(任せる,
見せる, 与える)의 られ는 목적어 뒤에서 가능으로 읽는다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 罰ゲームは、俺に頭を撫でられること。 | 벌칙 게임은, 내가 머리를 쓰다듬는 것. | 고침 |
| それを姉に見透かされた。 | 그것을 언니가 간파했다. | 고침 |
| 彼女に命を救われたあの男は、 | 그녀가 목숨을 구한 그 남자는, | 고침 |
| 母に本を読ませられた。 | 어머니가 책을 읽게 했다. | 고침 |
| 母に叱られた。 | 어머니에게 야단맞았다. | 유지 |
| 先生に褒められた。 | 선생님에게 칭찬받았다. | 유지 |
| 犬に噛まれた。 | 개에게 물렸다. | 유지 |
| 私に弟を任せられたから、 | 나에게 남동생을 맡길 수 있었으니까, | 유지 |

사례: `tests/rules/cases/grammar-agent-passive.tsv`

## GRM-3 주고받는 보조 동사는 해 주는 사람을 주어로 옮긴다

사람 뒤의 に에 이어지는 てもらう, ていただく는 그 사람이 해 준 일로 옮긴다. に의 사람은 주어 `(이)가`가 되고
동사는 `-어 주다`, ていただく는 `-어 주시다`로 옮긴다. する 명사나 목적어 뒤의 してもらう도 같고, 앞에 해 주는 사람이
없으면 `받다`(지도를 받다, 진찰받다)로 둔다. 부사, く형 형용사, ように 뒤의 してもらう는 `해 주다`다. 권유의
てもらおう, てもらいましょう와 명령의 てもらえ는 `-어 달라고 하다`로 옮기고, に의 사람은 `에게`로 둔다.
사역형 뒤(させていただく, 飲ませてもらおう)와 てくれる, てくださる, てあげる, てやる는 이 규칙이 바꾸지 않는다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 祖母に昔話をしてもらった。 | 할머니가 옛날이야기를 해 주었다. | 고침 |
| 生徒に協力してもらったアンケートです | 학생이 협력해 준 앙케이트입니다 | 고침 |
| 先輩に優しくしてもらったから | 선배가 다정하게 해 주었으니까 | 고침 |
| 先生に説明していただいた。 | 선생님이 설명해 주셨다. | 고침 |
| ハンカチを拾って頂きありがとうございました。 | 손수건을 주워 주셔서 감사합니다. | 고침 |
| 撮影したデータを消してもらおうか。 | 촬영한 데이터를 지워 달라고 할까. | 고침 |
| 時々、英会話の指導をしてもらっていた。 | 가끔, 영어회화 지도를 받고 있었다. | 유지 |
| 治療を十分にしてもらった。 | 치료를 충분히 받았다. | 유지 |
| 貴社に訪問させていただきます。 | 귀사에 방문하겠습니다. | 유지 |
| 友達が手伝ってくれた。 | 친구가 도와 주었다. | 유지 |
| 妹に本を読んであげた。 | 여동생에게 책을 읽어 주었다. | 유지 |

사례: `tests/rules/cases/grammar-benefactive.tsv`, `tests/rules/cases/benefactive-provider-subject.tsv`

## GRM-4 과거의 버릇을 말하는 たものだ는 `-곤 했다`다

같은 절에 자주, 늘, 옛날을 뜻하는 말(よく, いつも, 昔 같은 말. 문장을 여는 よく는 빼고)이 있고 문장 끝(또는 だが 앞)에 오는
과거형 동사 + ものだ, もんだ는 예전에 되풀이하던 일로 `-곤 했다`로 옮기고, 그 よく는 `자주`다. 부정형, 문장을 여는
よく, 쉼표나 も가 뒤따르는 よく, 인용의 と 뒤 よく(とはよく言ったものだ), 감탄의 だな, だね, だわ, ものだから, 사이에 다른
동사가 있는 절, ことだ는 바꾸지 않는다. 따옴표 안의 부드러운 말투에서는 `-곤 했어`다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 子供の頃、祖母によく昔話をしてもらったものだ。 | 어릴 적, 할머니가 자주 옛날이야기를 해 주곤 했다. | 고침 |
| 昔はよく泣いたものだ。 | 옛날은 자주 울곤 했다. | 고침 |
| 学生時代は毎晩飲み歩いたものだった。 | 학생시절은 매일 밤 마시며 돌아 다니곤 했었다. | 고침 |
| 昔は、つんけんしていたものだが。 | 옛날은, 뾰루퉁 하고 있곤 했지만. | 고침 |
| 昔はよく遊んだもんだよ。 | 옛날은 자주 놀곤 했어. | 고침 |
| 両家の親はよく、そんな話を了承したものだな。 | 양가의 부모는 잘, 그런 이야기를 승낙한 것이네. | 유지 |
| 読書の秋とはよく言ったものだ。 | 독서의 가을이라고는 잘 말한 것이다. | 유지 |
| この前デートした時に撮ったものだ。 | 일전에 데이트했을 때 찍은 것이다. | 유지 |
| クライアントと何度も会議を重ねて決めたものだ。 | 클라이언트와 몇 번이나 회의를 거듭해 결정한 것이다. | 유지 |

사례: `tests/rules/cases/grammar-habitual-mono.tsv`, `tests/rules/speech-soft/grammar-habitual-mono.tsv`,
`tests/rules/speech-strict/grammar-habitual-mono.tsv`

## GRM-5 아슬아슬하게 피한 일의 ところだった는 -(으)ㄹ 뻔했다로 옮긴다

사전형 동사 뒤의 ところだった, ところでした는 그 일이 일어나기 직전이었다는 뜻이다. 같은 문장 앞에 아슬아슬함을
나타내는 말(危うく, もう少しで, 一歩間違えば, 危なかった)이나 부정 조건(いなかったら)이 있거나, 동사가 수동(される,
られる), しまう, 忘れる이면 일어나지 않고 넘어간 일이므로 -(으)ㄹ 뻔했다로 옮긴다. 그 밖에는 막 하려던 때이므로
-(으)려던 참이었다로 옮긴다. ていたところだった, たところだった와 장소 ところ는 그대로 둔다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 危うく電車に乗り遅れるところだった。 | 하마터면 전철을 놓칠 뻔했다. | 고침 |
| 大事なことを忘れるところでした | 소중한 일을 잊을 뻔했습니다 | 고침 |
| うううぅっ、騙されるところだった～っ | 우우우웃, 속을 뻔했다~ | 고침 |
| もう少しで倒れるところだった。 | 거의 쓰러질 뻔했다. | 고침 |
| ちょうど白崎がやってくるところだった。 | 마침 시라사키가 오려던 참이었다. | 유지 |
| 彼は手紙を書くところだった。 | 그는 편지를 쓰려던 참이었다. | 유지 |
| ちょうどお兄様が帰宅したところだった。 | 마침 형님이 귀가한 참이었다. | 유지 |
| 望むところだ。 | 바라던 바다. | 유지 |

사례: `tests/rules/cases/grammar-tokoro-datta.tsv`

## GRM-6 용언 뒤 くせに는 -(으)면서, 명사 뒤 のくせに는 주제에다

동사, 형용사 뒤의 くせに, くせして(癖に, クセに)는 앞 절과 어긋나는 일을 탓하는 말로, 앞 용언을 -(으)면서로 잇는다
(과거는 -았으면서). 명사와 の 뒤에서는 `N 주제에`로 옮기고 의를 쓰지 않는다. な형 명사 뒤(深層心理なくせに)도 주제에다.
버릇의 癖(癖になる, 癖がある, 口癖)는 그대로 버릇이다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 知っているくせに教えてくれない。 | 알고 있으면서 가르쳐 주지 않는다. | 고침 |
| 何も知らないくせに！ | 아무것도 모르면서! | 고침 |
| 裏切ったくせに。拒絶したくせに。 | 배반했으면서. 거절했으면서. | 고침 |
| 知ってるくせして黙ってた。 | 알고 있으면서 입을 다물었다. | 고침 |
| 子供のくせに生意気だ。 | 아이 주제에 건방지다. | 고침 |
| 子供の癖に、 | 아이 주제에, | 고침 |
| 爪を噛む癖がある。 | 손톱을 물어뜯는 버릇이 있다. | 유지 |
| 自分でさせないと癖になりますよ | 스스로 시키지 않으면 버릇이 돼요 | 유지 |

사례: `tests/rules/cases/grammar-kuseni.tsv`

## GRM-7 과거 주절 앞의 반사실 조건은 -았더라면이다

ば, たら 조건 뒤의 주절이 과거이고 그 조건이 실제로는 일어나지 않은 일이면 조건을 -았더라면(부정은 -지 않았더라면)으로
옮긴다. ている, ない의 ば 조건(ていれば, ていなければ, いなければ, なければ)은 문장이 과거로 끝나면 반사실이다. 그 밖의
ば, たら 조건은 문장이 과거와 함께 のに, かもしれない, だろう, はず로 끝날 때 반사실이다. 인용(と, って) 안의 조건,
と 뒤의 조건(としたら), 의무(なければならない), もいなければ의 나열, 보기와 말하기의 조건(見れば, 言えば, 考えてみれば),
현재 주절은 그대로 -(으)면이다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 雨が降っていなければ、試合は中止にならなかった。 | 비가 오지 않았더라면, 시합은 중지가 되지 않았다. | 고침 |
| もっと早く来ていれば間に合ったのに。 | 좀 더 빨리 와 있었더라면 늦지 않았는데. | 고침 |
| お金があれば買えたのに。 | 돈이 있었더라면 살 수 있었는데. | 고침 |
| 君がいなければ、僕は死んでいた。 | 네가 없었더라면, 나는 죽어 있었다. | 고침 |
| 雨が降っていなければ、試合は中止になる。 | 비가 오지 않으면, 시합은 중지가 된다. | 유지 |
| 窓を開ければ海が見えた。 | 창을 열면 바다가 보였다. | 유지 |
| 行かなければならなかった。 | 가야 했다. | 유지 |
| 傍から見れば、ただ遊んでいるだけに見えただろう。 | 옆에서 보면, 다만 놀고 있는 만큼 보였을 것이다. | 유지 |

사례: `tests/rules/cases/grammar-counterfactual.tsv`
