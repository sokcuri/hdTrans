# 소리

## SND-1 소리는 한 덩어리로, 말더듬은 같은 음절로 옮긴다

한 번 내는 소리는 안에 공백이 없는 한국어 소리 하나로 옮기고 길이를 대략 맞춘다. 말더듬은 이어지는 낱말의 첫
음절을 되풀이해 옮긴다. 의태어, 의성어 뒤의 と는 하고로 옮기거나 빼고, 과, 와, 라고로 옮기지 않는다.

현재: 따름

| 원문 | 출력 | 구분 |
|---|---|---|
| ひぃやあああ | 히이야아아아 | 고침 |
| と、とと、溶けちゃう | 노, 노, 녹아버린다 | 고침 |
| 「さ、さ、最低」 | 「최, 최, 최저」 | 고침 |
| 彼女はもぞもぞとお尻を動かした。 | 그녀는 꼼지락꼼지락 엉덩이를 움직였다. | 고침 |
| すごおおおい！ | 대단해~! | 고침 |
| 「わ、わ、わたし……」 | 「나, 나, 나……」 | 유지 |
| じろじろと見る | 빤히 본다 | 유지 |

사례: `tests/rules/cases/sound-stutter-pieces.tsv`, `tests/rules/cases/sound-adverbial-to.tsv`(말더듬과 と),
`tests/rules/cases/sound-drawn-cries.tsv`(소리의 길이), `tests/rules/cases/sound-vowel-run.tsv`(낱말 안에서 늘인 모음)

## SND-2 되풀이한 말은 사본마다 같은 말로 옮긴다

같은 낱말이나 활용형을 바로, 또는 쉼표를 사이에 두고 두 번 이상 되풀이하면 사본마다 그 말을 홀로 쓸 때와 같은 말로
읽는다(어미는 그 자리의 말투 규칙을 따른다). 뒤 사본을 앞 사본에 붙는 조사나 어미로 읽거나 사본 경계를 넘어 다시
나누지 않는다. 어미는 한국어로 쓰는 사람이 쓰는 꼴을 따른다.

- 바로 이어 쓴 사본이 문장의 마지막 서술어이거나, 느낌표나 물음표로 끝나는 문장의 동사이면 앞 사본도 마지막 사본과
  같은 꼴로 쓴다(`싫다 싫다`, `기다려 기다려`, `봐 봐, 어때?`).
- 바로 이어 쓴 て형이 뒤 서술어로 이어지거나, 서술문 끝에서 동사로 끝나면 앞 사본은 `-고 또`로 잇는다(`걷고 또 걸어`,
  `슬프고 또 슬퍼`). 부사형 사본은 규칙대로 둔다(`길고 길게`).
- 쉼표나 말줄임으로 끊긴 앞 사본은 홀로 쓸 때처럼 읽고, 앞 사본만 연결 어미 `-고`를 갖지 않는다(`좋아해, 좋아해서`,
  `기뻐서, 기뻐서`).
- 부사나 감탄사 사본은 마지막 사본의 말로 맞춘다(`왜 왜`). 조사나 계사 앞 사본은 제 꼴을 둔다(`나, 내가`).
- 한 음절로 읽는 감탄사 사본은 원문처럼 붙여 쓴다(`네네네`). 사전에 되풀이한 꼴로 실린 낱말(`いろいろ`, `はいはい`)은
  그 낱말이다. 가타카나만 쓴 되풀이는 소리 말이다.
- `だって`를 되풀이하면 `그치만`, `でも`는 `하지만`, `ねえねえ`는 `있잖아`이다.

현재: 따름. 앞에 가나 낱말이 붙은 가나 사본(`やっぱりいやだいやだ`)과 말줄임으로 끊긴 `だって……だって`는 아직
따르지 않는다.

| 원문 | 출력 | 구분 |
|---|---|---|
| `いやだいやだ` | `싫다 싫다` | 고침 |
| `はいはいはい！` | `네네네!` | 고침 |
| `だってだってだってしょうがないじゃん` | `그치만 그치만 그치만 어쩔 수 없잖아` | 고침 |
| `待って待って！` | `기다려 기다려!` | 고침 |
| `「さ、入って入って」` | `「자, 들어가 들어가」` | 고침 |
| `歩いて歩いて、町に着いた。` | `걷고 또 걸어, 마을에 도착했다.` | 고침 |
| `「なんでなんで？」` | `「왜 왜?」` | 고침 |
| `「いやだいやだ」` (말투 soft) | `「싫어 싫어」` | 고침 |
| `長く長く話した。` | `길고 길게 이야기했다.` | 유지 |
| `「好きで、好きで……たまらないのに」` | `「좋아해, 좋아해서……견딜 수 없는데」` | 유지 |
| `いろいろ` | `여러 가지` | 유지 |
| `他にいないなんて` | `그 밖에 없다니` | 유지 |
