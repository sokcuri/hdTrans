# 배치

예의 공백은 원문과 출력에서 그대로 보이도록 코드로 적습니다.

## LAY-1 두 칸 이상의 공백과 탭은 칸 구분이다

반각 공백, 전각 공백이나 둘이 섞인 두 칸 이상의 공백과 모든 탭은 칸 구분으로 보고 원문 그대로 둔다. 칸 구분을
사이에 두고 낱말을 잇거나 붙이거나 띄어쓰기를 바꾸지 않고, 양쪽을 따로 번역한다. 다음 두 경우는 칸 구분이 아니다.

- 한자 한 글자, 공백, 한자 한 글자로 된 이름 맞춤(`林  涛`)
- 절 안의 반각 공백 정확히 두 칸: 왼쪽이 조사나 활용 어미로 끝나거나, 오른쪽이 계사, 보조 용언, 조사나 문장 부호로
  시작할 때

| 원문 | 출력 | 구분 |
|---|---|---|
| `名前      職業      状態` | `이름      직업      상태` | 고침 |
| `１７　　　医者　　　浮遊中` | `17　　　의사　　　부유 중` | 고침 |
| `山田　 太郎` | `야마다　 타로` | 고침 |
| `男    : 「なんだよ。」` | `남자    : 「뭐야.」` | 고침 |
| `林  涛` | `임도` | 유지 |
| `猫が  好き  です` | `고양이를 좋아합니다` | 유지 |
| `私は  学生です  。` | `저는 학생입니다  .` | 유지 |

사례: `tests/rules/cases/column-separators.tsv`, `tests/rules/cases/rules-layout.tsv`,
`tests/unit/engine/column_gap_test.cpp`(탭)

## LAY-2 공백 한 칸과 들여쓰기는 보통대로 다룬다

반각 공백 한 칸과 전각 공백 한 칸은 칸 구분이 아니며 보통의 띄어쓰기로 다룬다. 줄 첫머리의 들여쓰기는 같은 칸
수로 남긴다.

| 원문 | 출력 | 구분 |
|---|---|---|
| `高橋　聖` | `타카하시 성` | 유지 |
| `暗示？　カギ？　悪魔の血？` | `암시? 열쇠? 악마의 피?` | 유지 |
| `山田 太郎が来た。` | `야마다 타로가 왔다.` | 유지 |
| `　彼は来た。` | ` 그는 왔다.` | 유지 |
| `　　日本の首都は東京です。` | `  일본의 수도는 도쿄입니다.` | 유지 |

사례: `tests/rules/cases/column-separators.tsv`

## LAY-3 라틴 문자와 숫자 뒤 조사는 붙인다

라틴 문자나 숫자 낱말 뒤의 일본어 조사는 원문에 공백이 있어도 한국어에서 붙여 쓴다. 칸 구분(LAY-1)을 사이에 둔
조사는 붙이지 않는다.

| 원문 | 출력 | 구분 |
|---|---|---|
| `詳しくはwiki の記事を見てください。` | `자세하게는 wiki의 기사를 봐 주세요.` | 고침 |
| `API を呼び出す。` | `API를 호출한다.` | 고침 |
| `GitHub に上げた。` | `GitHub에 올렸다.` | 고침 |
| `wiki      の記事` | `wiki      의 기사` | 유지 |
| `「GitHub」に登録した。` | `「GitHub」에 등록했다.` | 유지 |

사례: `tests/rules/cases/latin-word-particles.tsv`, `tests/rules/cases/column-separators.tsv`,
`tests/rules/cases/rules-layout.tsv`

## LAY-4 루비 표기는 남긴다

루비 표기 `{rb}…{/rb}{rt}…{/rt}`는 출력에 남긴다. 루비 바탕 글자 뒤의 오쿠리가나는 바탕과 읽기 양쪽 안으로 옮겨
함께 번역한다.

| 원문 | 출력 | 구분 |
|---|---|---|
| `{rb}微{/rb}{rt}かす{/rt}かに声が聞こえる。` | `{rb}희미하게{/rb}{rt}희미하게{/rt} 목소리가 들린다.` | 고침 |
| `ネギを{rb}背負{/rb}{rt}しょ{/rt}って……？` | `파를 {rb}짊어져{/rb}{rt}짊어져{/rt}……?` | 고침 |
| `{rb}現実{/rb}{rt}ここ{/rt}に彼女はいない` | `{rb}현실{/rb}{rt}여기{/rt}에 그녀는 없다` | 유지 |
| `俺も{rb}安堵{/rb}{rt}あんど{/rt}する。` | `나도 {rb}안도{/rb}{rt}안도{/rt}한다.` | 유지 |

사례: `tests/rules/cases/ruby-brace-tags.tsv`
