# 숫자와 띄어쓰기

## NUM-1 수량을 나타내는 말은 앞 숫자에 붙인다

숫자나 라틴 문자 낱말 바로 뒤에 그것을 세거나 재는 조수사, 단위, 접미사가 오면 붙여 쓴다. 등급 글자는 뒤의 등급
낱말에 붙여 쓴다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 1レベル上がった。 | 1레벨 올랐다. | 고침 |
| 5ポイント獲得した。 | 5포인트 획득했다. | 고침 |
| 第一王子が来た。 | 제1왕자가 왔다. | 고침 |
| S級の魔物だ。 | S급의 마물이다. | 고침 |
| 10cm砲を撃つ。 | 10cm포를 쏜다. | 유지 |
| 1000Gを貸して | 1000G를 빌려 줘 | 유지 |
| コミックス第9巻 | 코믹스 제9권 | 유지 |
| Aランクの冒険者。 | A랭크의 모험가. | 유지 |

사례: `tests/rules/cases/number-noun-spacing.tsv`, `tests/rules/cases/ordinal-number-spacing.tsv`,
`tests/rules/cases/rules-numbers.tsv`

## NUM-2 앞말에 딸린 번호와 라틴 문자 이름은 뒤 명사와 띄운다

숫자나 라틴 문자 표지가 앞 낱말의 번호나 이름이면 뒤에 오는 명사와 띄어 쓴다. 명사 앞의 라틴 문자 약어나 이름도
띄어 쓴다.

현재: 따름

| 원문 | 출력 | 구분 |
|---|---|---|
| ステージ3ボス戦 | 스테이지 3 보스전 | 고침 |
| Lv.10スキル習得 | Lv.10 스킬 습득 | 고침 |
| No.2-1キャラクター設定 | No.2-1 캐릭터 설정 | 고침 |
| ATBゲージ | ATB 게이지 | 고침 |
| Essex class航空母艦 | Essex class 항공모함 | 유지 |
| Gato級潜水艦 | Gato급 잠수함 | 유지 |

사례: `tests/rules/cases/number-label-spacing.tsv`

## NUM-3 수가 아닌 표지 뒤는 띄운다

댓글 번호, 시각, 표지로 쓴 네 자리 연도처럼 수량이 아닌 숫자 뒤의 낱말은 띄어 쓴다.

| 원문 | 출력 | 구분 |
|---|---|---|
| ≫372過疎 | ≫372 과소 | 고침 |
| ５/１４　２３：４０追記 | 5/14 23：40 추기 | 고침 |
| バレンタイン2026特別限定任務 | 발렌타인 2026 특별 한정 임무 | 고침 |
| 2300 提督 | 2300 제독 | 유지 |

사례: `tests/rules/cases/number-noun-spacing.tsv`, `tests/rules/cases/rules-numbers.tsv`

## NUM-4 숫자, 라틴 문자 뒤 원문의 띄어쓰기는 그대로 둔다

원문에서 숫자나 라틴 문자 낱말과 다음 낱말 사이에 공백이 있으면 출력에도 둔다. 다음 낱말이 조수사나 단위여도
같고, 조수사는 붙어 있을 때와 같게 읽는다. Ehnd 필터를 켜도 같다.

현재: 따름. 다만 전각 공백은 문장 조각을 가르므로 그 뒤의 조수사는 따로 읽힌다
(１２　月になった 12 달이 되었다).

| 원문 | 출력 | 구분 |
|---|---|---|
| 1 レベルだ。 | 1 레벨이다. | 고침 |
| A レベルだ。 | A 레벨이다. | 고침 |
| 2026 年に始まった。 | 2026 년에 시작했다. | 고침 |
| 3 年前の話だ。 | 3 년 전의 이야기다. | 유지 |
| 1レベル上がった。 | 1레벨 올랐다. | 유지 |

사례: `tests/rules/cases/number-noun-spacing.tsv`(필터를 끈 경우), `tests/unit/filter/filter_test.cpp`(필터를 켠 경우)

## NUM-5 아라비아 숫자는 아라비아 숫자로 쓴다

원문의 아라비아 숫자는 수의 크기와 조수사에 관계없이, 대사, UI, 설명문 어디서나 출력에서도 아라비아 숫자로 쓰고
조수사를 붙인다. 서수, 소수, 第 뒤의 수도 숫자로 쓴다. 고유어 수는 원문이 한자 숫자나 고유어 수에 해당하는 낱말을
쓸 때와 아래 관용구에서만 쓴다.

- 1과 조수사 뒤 残らず(남김없이): 한 명 남김없이.
- 1과 조수사를 また로 되풀이함: 한 명 또 한 명.
- 기간 뒤 に와 1度, 1回(기간마다 한 번): 100년에 한 번, 1일에 한 번.
- 낱말로 굳은 것: 1人で 혼자서, 1杯 한잔, 1度も 한 번도, 2度と 두 번 다시.

관용구의 1つ는 一つ처럼 하나로 쓴다(1つ残らず 하나 남김없이). 서수의 조수사는 고유어 수 뒤의 꼴로 쓰고(1つ目
1번째, 2回目 2번째), 1杯처럼 고유어 수로 굳은 낱말도 서수에서는 숫자로 쓴다(1杯目 1잔째). 回를 회와 번 가운데
무엇으로 읽는지는 NUM-7, 度는 NUM-6을 따른다.

현재: 따름

| 갈래 | 원문 | 출력 | 구분 |
|---|---|---|---|
| 숫자와 조수사 | 2回やった。 | 2회 했다. | 고침 |
| 숫자와 조수사 | 7枚の紙。 | 7장의 종이. | 고침 |
| 숫자와 조수사 | 1個だけ。 | 1개만. | 고침 |
| 숫자와 조수사 | やくそうを3個手に入れた！ | 약초를 3개 손에 넣었다! | 유지 |
| 숫자와 조수사 | 他の料理より銅貨2枚ほど安い。 | 다른 요리보다 동화 2장 정도 싸다. | 유지 |
| 숫자와 조수사 | 攻撃回数：2回 | 공격 횟수：2회 | 고침 |
| 큰 수 | 130箇所を回った。 | 130군데를 돌았다. | 유지 |
| 큰 수 | 130時間かかった。 | 130시간 걸렸다. | 유지 |
| 큰 수 | 111ヶ所の拠点 | 111군데의 거점 | 유지 |
| 소수 | 3.5キロ歩いた。 | 3.5킬로 걸었다. | 유지 |
| 서수 | 1つ目は手動回避 | 1번째는 수동 회피 | 고침 |
| 서수 | 2回目の挑戦 | 2번째의 도전 | 유지 |
| 서수 | 1杯目のコーヒー。 | 1잔째의 커피. | 고침 |
| 第 뒤의 수 | 第3王子が来た。 | 제3왕자가 왔다. | 유지 |
| 한자 숫자 | 二つください。 | 두 개 주세요. | 유지 |
| 한자 숫자 | 一度も見ていない。 | 한 번도 보지 않았다. | 고침 |
| 한자 숫자 | 一人で行く。 | 혼자서 간다. | 유지 |
| 관용구 | 1人残らず倒した。 | 한 명 남김없이 쓰러뜨렸다. | 고침 |
| 관용구 | 1つ残らず食べた。 | 하나 남김없이 먹었다. | 고침 |
| 관용구 | 100年に1度の天才。 | 100년에 한 번의 천재. | 고침 |
| 관용구 | 1度も負けていない。 | 한 번도 지지 않았다. | 고침 |
| 관용구 | 2度と来るな。 | 두 번 다시 오지 마. | 고침 |

## NUM-6 숫자 뒤 度는 각도와 온도일 때만 도로 읽는다

숫자 뒤의 度는 각도나 온도이면 도, 그 밖에는 횟수(번)로 읽는다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 十度も言った。 | 열 번이나 말했다. | 고침 |
| 百八十度変わった。 | 180도 바뀌었다. | 고침 |
| 十度目の挑戦だ。 | 열 번째 도전이다. | 유지 |
| 角度は四十五度だ。 | 각도는 45도다. | 유지 |
| 気温は三十度だ。 | 기온은 30도다. | 유지 |

사례: `tests/rules/cases/degree-after-number.tsv`, `tests/rules/cases/rules-numbers.tsv`

## NUM-7 숫자 뒤 回는 회로 읽고, 힘준 횟수와 대사의 동작 횟수는 번으로 읽는다

숫자 뒤의 回는 회로 읽는다. 고유어 수로 읽는 한자 숫자 뒤에서는 번이다(三回 세 번). 다만 뒤에 も나 でも가 붙어
횟수에 힘을 주거나, 「」나 『』 안의 대사에서 回 바로 뒤나 조사, 쉼표 뒤에 동사가 오면 번으로 읽는다. 어느 쪽이든
아라비아 숫자는 숫자로 쓴다(NUM-5). 第 뒤의 회차, 바로 앞의 회와 짝을 이룬 횟수(2回か3回, 5回中4回), 回戦과 回分
같은 합성어, 그 밖의 지문, UI, 설명문의 횟수는 회다.

현재: 따름

| 원문 | 출력 | 구분 |
|---|---|---|
| 100回も言った。 | 100번이나 말했다. | 고침 |
| ３回も言われた。 | 3번이나 들었다. | 고침 |
| 「初めてなのに２回も３回もしただろ？」 | 「처음인데 2번도 3번도 했지?」 | 고침 |

| 「ふたりでいるところに２回くらい出会ったじゃない？」 | 「둘이서 있는 곳에 2번 정도 만났잖아?」 | 고침 |
| 「ま、誰でも１回は考えるよな」 | 「뭐, 누구라도 1번은 생각하지」 | 고침 |
| 何回も言った。 | 몇 번이나 말했다. | 유지 |
| 攻撃回数：2回 | 공격 횟수：2회 | 유지 |
| 2回まで使用可能。 | 2회까지 사용 가능. | 유지 |
| 1日3回まで挑戦できる。 | 1일 3회까지 도전할 수 있다. | 유지 |
| 敵艦隊を10回邀撃せよ！ | 적함대를 10회 요격하라! | 유지 |

| 「1回戦で負けちまったのさ」 | 「1회전에서 져 버렸어」 | 유지 |
| 「2回か3回は言った」 | 「2회나 3회는 말했다」 | 유지 |
