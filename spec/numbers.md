# 숫자와 띄어쓰기

## NUM-1 수량을 나타내는 말은 앞 숫자에 붙인다

숫자나 라틴 문자 낱말 바로 뒤에 그것을 세거나 재는 조수사, 단위, 접미사가 오면 붙여 쓴다. 등급 글자는 뒤의 등급
낱말에 붙여 쓴다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 1レベル上がった。 | 1레벨 올랐다. | 고침 |
| 5ポイント獲得した。 | 5포인트 획득했다. | 고침 |
| 第一王子が来た。 | 제1왕자가 왔다. | 고침 |
| S級の魔物だ。 | S급의 마물이다. | 고침 |
| 10cm砲を撃つ。 | 10cm포를 쏜다. | 유지 |
| 1000Gを貸して | 1000G를 빌려 줘 | 유지 |
| コミックス第9巻 | 코믹스 제9권 | 유지 |
| Aランクの冒険者。 | A랭크의 모험가. | 유지 |

사례: `tests/rules/cases/number-noun-spacing.tsv`, `tests/rules/cases/ordinal-number-spacing.tsv`,
`tests/rules/cases/rules-numbers.tsv`

## NUM-2 앞말에 딸린 번호와 라틴 문자 이름은 뒤 명사와 띄운다

숫자나 라틴 문자 표지가 앞 낱말의 번호나 이름이면 뒤에 오는 명사와 띄어 쓴다. 명사 앞의 라틴 문자 약어나 이름도
띄어 쓴다.

현재: 0.4.6에서 맞춤

| 원문 | 출력 | 구분 |
|---|---|---|
| ステージ3ボス戦 | 스테이지 3 보스전 | 고침 |
| Lv.10スキル習得 | Lv.10 스킬 습득 | 고침 |
| No.2-1キャラクター設定 | No.2-1 캐릭터 설정 | 고침 |
| ATBゲージ | ATB 게이지 | 고침 |
| Essex class航空母艦 | Essex class 항공모함 | 유지 |
| Gato級潜水艦 | Gato급 잠수함 | 유지 |

사례: 없음

## NUM-3 수가 아닌 표지 뒤는 띄운다

댓글 번호, 시각, 표지로 쓴 네 자리 연도처럼 수량이 아닌 숫자 뒤의 낱말은 띄어 쓴다.

| 원문 | 출력 | 구분 |
|---|---|---|
| ≫372過疎 | ≫372 과소 | 고침 |
| ５/１４　２３：４０追記 | 5/14 23：40 추기 | 고침 |
| バレンタイン2026特別限定任務 | 발렌타인 2026 특별 한정 임무 | 고침 |
| 2300 提督 | 2300 제독 | 유지 |

사례: `tests/rules/cases/number-noun-spacing.tsv`, `tests/rules/cases/rules-numbers.tsv`

## NUM-4 숫자, 라틴 문자 뒤 원문의 띄어쓰기는 그대로 둔다

원문에서 숫자나 라틴 문자 낱말과 다음 낱말 사이에 공백이 있으면 출력에도 둔다. Ehnd 필터를 켜도 같다.

현재: 0.4.6에서 맞춤

| 원문 | 출력 | 구분 |
|---|---|---|
| 1 レベルだ。 | 1 레벨이다. | 고침 |
| A レベルだ。 | A 레벨이다. | 고침 |
| 1レベル上がった。 | 1레벨 올랐다. | 유지 |

사례: `tests/rules/cases/number-noun-spacing.tsv`(필터를 끈 경우)

## NUM-5 아라비아 숫자는 아라비아 숫자로 쓴다

원문의 아라비아 숫자는 출력에서도 아라비아 숫자로 쓰고 조수사를 붙인다. 고유어 수는 원문이 고유어 수에 해당하는
낱말이나 한자 숫자 관용구를 쓸 때만 쓴다.

현재: 0.4.6에서 맞춤

| 원문 | 출력 | 구분 |
|---|---|---|
| 2回やった。 | 2회 했다. | 고침 |
| 7枚の紙。 | 7장의 종이. | 고침 |
| 1個だけ。 | 1개만. | 고침 |
| 一人で行く。 | 혼자서 간다. | 유지 |
| 一度も見ていない。 | 한 번도 보지 않았다. | 유지 |
| 一つください。 | 하나 주세요. | 유지 |

사례: 없음

## NUM-6 숫자 뒤 度는 각도와 온도일 때만 도로 읽는다

숫자 뒤의 度는 각도나 온도이면 도, 그 밖에는 횟수(번)로 읽는다.

| 원문 | 출력 | 구분 |
|---|---|---|
| 十度も言った。 | 열 번이나 말했다. | 고침 |
| 百八十度変わった。 | 180도 바뀌었다. | 고침 |
| 十度目の挑戦だ。 | 열 번째 도전이다. | 유지 |
| 角度は四十五度だ。 | 각도는 45도다. | 유지 |
| 気温は三十度だ。 | 기온은 30도다. | 유지 |

사례: `tests/rules/cases/degree-after-number.tsv`, `tests/rules/cases/rules-numbers.tsv`
