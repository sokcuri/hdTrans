# N5: grammar points, house forms and the grid

Level N5 of the 0.8 curriculum. Every N5 rule row names one id of this file in its `spec` column; the grid
(`poc08/tools/grid/`) composes its expected Korean from §2 and §3 and from the Korean paradigm, never from the
engine's transfer tables. Ids are stable; a removed id is not reused.

Status marks: **decided** (binding), **proposed** (used by the grid and the rules until the lead confirms or
changes it; a change moves the grid and the rules in the same commit).

## 1. House style

| id | rule | status |
|---|---|---|
| N5-H1 | Negation. Dialogue (해, 해요) uses the short form 안 + predicate: 안 먹어, 안 가요, 안 비싸. A 하다 compound puts 안 before 하다: 공부 안 해. Narration (해라) and 합쇼 use the long form -지 않다: 먹지 않는다, 가지 않습니다. 있다/없다, 알다/모르다 and 이다/아니다 are suppletive: ない of ある → 없다, 知らない/分からない → 모르다, じゃない → 이/가 아니다 | decided |
| N5-H2 | て linking two predicates: -어서 when the first clause is a cause, a means or manner, or a motion or posture whose end place or state the second action uses (行って買う → 가서 사다, 座って話す → 앉아서 이야기하다), or when both share one object (パンを買って食べる → 빵을 사서 먹다); -고 for plain sequence of separate actions, listing, contrast or a holding state (食べて寝る → 먹고 자다, 手を洗って食べる → 손을 씻고 먹다) | decided |
| N5-H3 | から (reason): in dialogue -니까 (the speaker's reason), before any main clause: 「雨が降るから、行かない」 → 「비가 내리니까, 안 가」. In narration -니까 when the main clause is an imperative, request, invitation or question, else -어서 for a cause. A past reason is -었으니까, never -었어서. ので: as から. Changed from -어서 before dialogue statements: measured by the gate | proposed |
| N5-H4 | と (listing nouns): narration 와/과; dialogue 하고, and 랑/이랑 at 해 level | decided |
| N5-H5 | Speech level. Narration (an unquoted line) plain → 해라 (-다). Dialogue (a line inside 「」) plain → 해 (-어, -야), never 해라 -다. です/ます dialogue → 해요. 합쇼 only with keigo or a formal or announcement register. A source 命令形 command keeps 해라 (見ろ → 봐라) | decided |
| N5-H6 | Unquoted です/ます: a line with a speaker tag or in a dialogue context (game or VN lines without 「」) is dialogue → 해요; plain narration, documents, notices and descriptions → 합쇼. Not in the N5 grid (the context is R's decision) | decided |
| N5-H7 | A question marked by か (or a rising plain question ending in ？) ends in ? in Korean; 。 after か becomes ?: 行きますか。 → 가요? | proposed |
| N5-H8 | ましょう → 해요 -죠 (가죠, 먹죠; 가요 would read as a statement); ましょうか → -ㄹ까요?; ませんか → -지 않을래요? Plain volitional (よう) is N4 | proposed |
| N5-H9 | N1 の N2 → N1의 N2 by default (友達の本 → 친구의 책, みんなの言葉 → 모두의 말); a personal pronoun takes its possessive form (私の → 내 / 해요 제, 君の → 네); a determiner sense absorbs the の (何の本 → 무슨 책). Changed from juxtaposition without 의: measured by the gate | proposed |
| N5-H10 | Person + に/から with a giving, telling or receiving verb: narration 에게 / 에게서, dialogue 한테 / 한테서 (the generator's particles.tsv person rows; STYLE §7) | decided |
| N5-H11 | よ adds nothing at N5 (行くよ → 가); ね after a statement is -네 at 해, -네요 at 해요 (高いですね → 비싸네요); ね/よ only after adjectives, the copula and ある/いる in the grid | proposed |
| N5-H12 | Demonstrative pronouns in dialogue take the spoken forms 이거, 그거, 저거, 뭐 (with particles 이걸, 그건); narration 이것, 그것, 저것, 무엇 | proposed |
| N5-H13 | たり〜たりする → -거나 -거나 하다 (読んだり見たりする → 읽거나 보거나 하다) | proposed |
| N5-H14 | でしょう (conjecture) → -ㄹ 거예요; だろう → dialogue -ㄹ 거야, narration -ㄹ 것이다 | proposed |
| N5-H15 | ている with a negative: an activity verb → -고 있지 않다 (narration), 안 -고 있다 (dialogue): 読んでいない → 읽고 있지 않다 / 안 읽고 있어; a posture verb → -어 있지 않다 / 안 -어 있다 (座っていない → 안 앉아 있어); any other change verb → the plain negative past, also for ていなかった (来ていない, 来ていなかった → 오지 않았다 / 안 왔어). A change-past verb is the plain past (結婚している, 結婚していた → 결혼했다; 結婚していなかった → 결혼하지 않았다). No -었었- in N5. まだ〜ていない is N5-52 | decided |
| N5-H16 | 私 as a word: 나 in narration and at 해, 저 at 해요; 私は → 난 at 해 (N5-H17), 私が → 내가 / 제가; 私の → N5-H9 | proposed |
| N5-H17 | Spoken forms follow the register (STYLE §7): dialogue fuses as the generator's spoken.tsv lists (것이 → 게, 것은 → 건, 것을 → 걸, 할 것이다 → 할 거다, 이것은 → 이건, 이것을 → 이걸, 무엇을 → 뭘, 무엇이야 → 뭐야, 나는 → 난, 너는 → 넌); narration keeps 것이, 것을, 나는, 이것은, 무엇. 나가/저가/누구가 → 내가/제가/누가 everywhere. So 読むのが好き → 읽는 것을 좋아한다 / 「읽는 걸 좋아해」 and 方がいい → 하는 것이 좋다 / 「하는 게 좋아」 | decided |
| N5-H18 | ほしい takes the negative of たい: ほしくない → 갖고 싶지 않다 at every level (N5-44, N5-45) | proposed |
| N5-H19 | ませんか after a volitional verb is the invitation (N5-30); the grid has no negative polite question of a volitional verb without a question word (どうして行きませんか → 왜 안 가요? keeps the question). A plain 〜ない？ is a negative question (食べない？ → 안 먹어?) | proposed |
| N5-H20 | A plain dialogue question is written without か and ends in ？ (食べる？ → 먹어?). A bare noun keeps the noun with no copula (学生？ → 학생?, 外？ → 밖?, 何？ → 뭐?); a past or negative noun predicate conjugates (学生だった？ → 학생이었어?); a な-adjective conjugates (便利？ → 편리해?, 静か？ → 조용해?). The bare noun is measured by the gate | proposed |
| N5-H21 | Polarity inside でしょう/だろう and つもり follows N5-H1: 食べないでしょう → 안 먹을 거예요, narration 食べないだろう → 먹지 않을 것이다, 行かないつもりだ → 가지 않을 생각이다 / 「안 갈 생각이야」. Tense: だろう's past is inside (食べただろう → 먹었을 것이다), つもり's past is on 생각 (行くつもりだった → 갈 생각이었다) | proposed |
| N5-H22 | Counters (N5-56): native numeral + 개 (つ; 一つ alone → 하나), 명 (人), 장 (枚), 권 (冊), 번 (回), 시 (時), 살 (歳, 二十歳 → 스무 살), 자루 (本 with a pen); Sino-Korean + 분 (分), 엔 (円); a written numeral is spaced from the counter (세 개, 백 엔), digits attach (3명, 100엔) | proposed |
| N5-H23 | もう takes its lexicon sense: + past → 벌써 (cue form=ta: もう宿題をした → 벌써 숙제를 했다); otherwise sense 1 이제 (もう来ない → 이제 오지 않는다 / 「이제 안 와」). Earlier proposal 더 이상 for もう + negative is withdrawn | proposed |

## 3. Grid

Dimensions and their N5 values are PLAN-v3 §1.2. The grid draws its lemmas only from the controlled vocabulary
(`poc08/tools/grid/vocab.tsv`, a subset of the N5 lexicon rows, sense 1 or the sense its frame selects).

Validity (`tools/grid/valid.tsv`, a cell outside these is not generated):
- request, prohibition and invitation only with volitional verbs, in dialogue, at です/ます;
- たい, ている, てから, ながら, たり only with verbs; ほしい only with nouns;
- ある with things, いる with animates;
- a question in dialogue only; narration has statements only;
- です/ます only in dialogue (N5-H6);
- 昨日 and other past time nouns only with past, 明日 only with nonpast;
- ている progressive only with activity verbs, result only with change verbs.

The Japanese side of the grid writes: plain noun and な-adjective negatives as ではない in narration and じゃない in
dialogue, じゃありません at です/ます; い-adjective polite negatives as くないです; 、 only after a から, が or けど
clause (Korean , there, nowhere else); no third-person subject in たい and つもり lines.

The Korean of every lemma is its N5 lexicon sense (`lexicon/lex/levels/n5.tsv`, sense rows in
`lexicon/curriculum.tsv`), chosen by the lexicon's reference rule (`lexicon/tools/senses.py`) from the grid's context
(arguments by particle, form, register, head, next); kcls and te come from the lexicon too. `tools/grid/disputes.tsv`
lists where the grid keeps its house form until the lexicon is settled; lemmas the lexicon lacks keep the gloss in
`tools/grid/vocab.tsv`.

Each grid row is `id dims ja ko`, with `dims` the cell key (`dimension=value` joined by `;`); the pass table is
per cell and per dimension value.
