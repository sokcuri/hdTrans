# N4: grammar points, house forms and the grid

Level N4 of the 0.8 curriculum. Every N4 rule row names one id of this file in its `spec` column. The grid
(`poc08/tools/grid/`, level n4, tables in `poc08/tools/grid/n4/`) composes its expected Korean from §2 and §3 and from
the Korean paradigm, never from the engine's transfer tables. N4 builds on N5: every N5 house form (n5.md §1) holds
inside N4 lines. Ids are stable; a removed id is not reused.

Status marks as in n5.md: **decided** (binding), **proposed** (used by the grid and the rules until the lead confirms
or changes it; a change moves the grid and the rules in the same commit).

## 1. House style

| id | rule | status |
|---|---|---|
| N4-H1 | Explanatory のだ (んだ, のです, んです, の？, のか, んですか) in **dialogue** adds no Korean ending: the clause ends in its plain form at the line's level (N5-H5, N5-H20). 食べるんだ → 「먹어」, 食べるんです → 「먹어요」, どこへ行くの？ → 「어디에 가?」, 来たのか？ → 「왔어?」, どこへ行くんですか → 「어디에 가요?」. The more specific rows below (H2–H5) win | proposed |
| N4-H2 | のだ + ね (statement, dialogue) reads as the speaker's realization: 해 -구나, 해요 -군요 (行くんだね → 「가는구나」, 学生なんですね → 「학생이군요」). そうなんだ / そうなのか standing alone → 그렇구나, そうなんですか → 그래요? | proposed |
| N4-H3 | のだ + が / けど / けれど (んだけど, んですが, のだが) is the background link -는데 at every level, never -지만: 行きたいんだけど → 「가고 싶은데」, 学生なんですが → 「학생인데요」 (line-final) | proposed |
| N4-H4 | Explanatory のだ in **narration**: a verb or adjective predicate → -ㄴ 것이다 (行ったのだ → 간 것이다, 行くのだ → 가는 것이다, 高いのだ → 비싼 것이다); a noun or な-adjective predicate (なのだ) → the plain copula (学生なのだ → 학생이다). Narration のか (a self-question) → -ㄴ 건가 (来たのか。 → 온 건가., 学生なのか。 → 학생인 건가.); のだろう(か) → -ㄴ 걸까 | proposed |
| N4-H5 | Shapes of のだ held for 0.7.x until a row is written: んだろう in dialogue, のだった, line-final んで / ので as a reason, んじゃない (N3 rhetorical), のです in narration | proposed |
| N4-H6 | Potential (可能動詞, (ら)れる read as potential, できる, ことができる): positive -ㄹ 수 있다 at every level (読める → 읽을 수 있다). Negative: dialogue 못 + the verb (読めない → 「못 읽어」; a 하다 verb of kcls HA splits: 勉強できない → 「공부 못 해」); narration -ㄹ 수 없다 (読めない → 읽을 수 없다). ことができない → -ㄹ 수 없다 at every level | proposed |
| N4-H7 | (ら)れる is resolved to one voice by explicit rules over the clause, most specific first: (a) honorific: the subject is a person the speaker honours (a 先生/様/さん noun or a title as overt subject, or お/ご + noun + される) and no agent に/から/によって → -시- on the verb (先生が来られた → 선생님이 오셨다); (b) passive: an overt agent に/から/によって, or an inanimate subject (が/は) with a transitive verb and no object → passive (c); (c) potential: an object marked が on a transitive verb, or a negative with the speaker or no subject and no agent → N4-H6. A clause none of the rules decides is held for 0.7.x (line.route=fallback); the grid only uses decided cells | proposed |
| N4-H8 | Passive Korean is lexical: the verb's passive row in the voice table (呼ばれる → 불리다, 叱られる → 혼나다, 選ばれる → 뽑히다, 嫌われる → 미움받다, 断られる → 거절당하다, 紹介される → 소개되다); the agent に → 에게 (narration) / 한테 (dialogue) (N5-H10), an inanimate agent に → 에. A verb without a passive row is held for 0.7.x (no productive -어지다 / 당하다 by default) | proposed |
| N4-H9 | Causative させる → -게 하다 (行かせる → 가게 하다); the causee に/を → 을/를 for an intransitive verb's causee, 에게 for a transitive verb's causee (子供に本を読ませる → 아이에게 책을 읽게 하다). A lexical causative in the lexicon wins (食べさせる → 먹이다 when the row exists). させてください → -게 해 주세요 | proposed |
| N4-H10 | Volitional (よう/おう): dialogue plain → -자 (行こう → 「가자」); narration (monologue) → -자 as well (帰ろう。 → 돌아가자.); ようと思う → -려고 하다 (行こうと思う → 가려고 한다 / 「가려고 해」); ましょう stays N5-H8 | proposed |
| N4-H11 | と思う → -다고 생각하다 (行くと思う → 간다고 생각한다 / 「간다고 생각해」); と言う → -다고 하다 (indirect: 行くと言った → 간다고 했다), -라고 하다 after a noun (学生だと言った → 학생이라고 했다); a direct quote 「…」と言う → 「…」라고 하다 | proposed |
| N4-H12 | Conditionals: ば → -면; たら → -면, and before a past main clause of discovery -자 (only with a past main clause; else -면); と (conditional) → -면, and before a past main clause -자; なら → N(이)라면, verb/adjective -ㄴ다면 (行くなら → 간다면) | proposed |
| N4-H13 | Aspect auxiliaries: てしまう → -어 버리다; ておく → -어 두다; てみる → -어 보다; てある → -어 있다 when the verb's Korean has an intransitive (passive) pair in the voice table (書いてある → 쓰여 있다), else -어 두었다; ていく → -어 가다; てくる → -어 오다 (motion verbs keep the motion: 持ってくる → 가져오다 by the lexicon phrase) | proposed |
| N4-H14 | Giving and receiving: あげる/くれる → 주다, てあげる/てくれる → -어 주다; もらう → 받다; てもらう → the giver (に/から) becomes the subject of -어 주다 (友達に手伝ってもらった → 친구가 도와줬다); てほしい → -어 주면 좋겠다 (dialogue -어 줬으면 좋겠어) | proposed |
| N4-H15 | Obligation and permission: なければならない / なくてはいけない / なきゃ → -어야 하다; なくてもいい → -지 않아도 되다 (dialogue 안 -어도 되다) | proposed |
| N4-H16 | ように (purpose) → -도록; ようになる → -게 되다; ようにする → -도록 하다; ように (like, N のように) → 처럼 | proposed |
| N4-H17 | のに (concession) → -는데 (+ the main clause), line-final のに (regret) → -는데; ので → as から (N5-H3); し → -고; ても → -어도; ないで (without) → -지 않고, ないで + request → N5-27 | proposed |
| N4-H18 | Modal judgements: かもしれない → -ㄹ지도 모르다; はずだ → -ㄹ 것이다 (dialogue -ㄹ 거야), はずがない → -ㄹ 리가 없다; V-そうだ (look) → -ㄹ 것 같다, A-そうだ → -어 보이다; ようだ / みたいだ → -ㄴ 것 같다, N みたい → N 같다; らしい (hearsay) → -대 (해) / -대요 (해요) / -다고 한다 (narration); すぎる → 너무 + the predicate; やすい / にくい → -기 쉽다 / -기 어렵다; たがる → -고 싶어 하다; かどうか → -ㄴ지 어떤지 | proposed |
| N4-H19 | Plain imperative 命令形 → 해라 -어라 (見ろ → 봐라, N5-H5); prohibitive な after a dictionary form → -지 마 (dialogue), -지 마라 (authority) | proposed |
| N4-H20 | The 連用 clause link (連用中止: 読み、 / 入り、) is the written counterpart of て and follows N5-H2: -어 (not -어서) where て takes -어서 for a motion, posture or shared object (部室に入り、向かう → 들어가 향하다), -어서 for a cause (an adjective, a passive or a non-volitional first clause), -고 otherwise (蓋を開け、水を飲む → 뚜껑을 열고 물을 마시다). The comma follows the source (STYLE §13) | proposed |
| N4-H21 | Basic 敬語: いらっしゃる → 계시다 (existence), 오시다/가시다 (motion, by the goal or source); お〜になる → -시-; おります → 있습니다 (existence), -고 있습니다 (after て); ございます → 있습니다, でございます → 입니다; the level is 합쇼 when the line is 敬語 (N5-H5) | proposed |

## 3. Grid

The N4 grid (`tests/grid/n4.tsv`, `grid.py --level n4`) uses the N5 dimensions (n5.md §3) and adds, per block:

| block | dimensions (N4 values) |
|---|---|
| n4noda | pred (verb classes, i-adj, na-adj, noun-cop) × noda (noda, noda-ne, noda-kedo) × ctx.polite × stype (statement, question) × tense × pol |
| n4voice | pred (verbs with a passive or potential reading in the voice table) × voice (pot, pass, hon, caus) × ctx.polite × stype × tense × pol |
| n4renyou | the link pairs of `n4/links.tsv` × link (renyou) × ctx (narration; dialogue on a subset) × tense |
| n4mod | pred × mod (shimau, oku, miru, nakereba, nakutemoii, kamo, hazu, sou, mitai, sugiru, yasui, nikui, tagaru, dekiru, younaru) × ctx.polite × tense × pol |
| n4link | pairs × link (ba, tara, to, nara, noni, node, temo, shi, naide, tame, youni) × ctx.polite × tense |
| n4final | pred × stype (imperative, volitional, prohibitive-na) × ctx |

Validity adds (`n4/valid.tsv`): potential only with volitional verbs; passive with an agent only with transitive verbs
of the voice table; honorific only with a person subject the speaker honours (先生); causative only with volitional
verbs; のだ + ね in dialogue statements only; のだ + けど as a two-clause line or line-final; volitional and
imperative in dialogue or narration monologue, never with past or negative.

Each grid row is `id dims ja ko`, as at N5; the pass table is per cell and per dimension value.
